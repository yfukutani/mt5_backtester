# FXRISK 第1ラウンド

固定ロット枠のrisk%化で月利5%への余地を調べる掃引ハーネス。
FX 9枠の構成は `ml/fxcomp1/measure.py` を継承する。
対象は RSI USDJPY / EURUSD / GBPUSD（bit0〜2）と
SCA USDJPY / GBPJPY（bit3〜4）。Pairは2脚・Z基準SLのため対象外。
入力名・ビット割り当ての正は `experts/MIX_EA_SIMVERIFY.mq5`。

## 提案

| family | 内容 | 案数 |
|---|---|---:|
| A | 現行固定ロットの基準比較 | 4 |
| B | 5枠を個別に有効化 | 5 |
| C | RSI 3枠 | 6 |
| D | SCA 2枠 | 6 |
| E | 全5枠・低リスク域 | 6 |
| F | 全5枠・倍率2/3 | 4 |
| G | 完全複利・倍率1/2 | 6 |
| H | 中間値0.15/0.35/0.75%による細分 | 7 |

計44案（A〜Gの37案＋Hの7案）、重複0件。R001は現行構成
（マスク0・risk 0.5%・FxRiskRefCap=0・RefCap=78000・倍率1）。
枠別重みは全1.0。PB USDJPY / PB GBPJPY / Carry の3つのRefCapは
常に同値で、BASEに置かず各案で指定する。BASEのラボ既定は
`FxRiskMask=0 / FxRiskPct=0.5 / FxRiskRefCap=0`。
Hは実測による有望判定ではなく、低リスク全枠と群別の中間値を優先する事前仮説。

## 窓と破綻リスク

入金500,000円、FULL=2016.11.09〜2026.06.20（115か月）、
OOS=2016.11.09〜2021.06.20（55か月）。44案×2窓で計88測定を予定する。
各窓でR001を先に取得し、取引数が基準の半分未満なら `blown=True`、
判定不能なら空欄。これは破綻の暫定代理指標であり確定診断ではない。

Gは9枠中8枠がequity連動となり、破綻リスクが最も高い。
前ラウンドでは既存3枠だけの複利・倍率3でも最大DD約57%だった。
Fの倍率増加やC/Dの1.0%もDD増大に注意が必要な比較条件。
各群は低いrisk%から並べ、Hも倍率1とする。

## 生成と評価

Python 3.7以降で `python ml/fxrisk1/generate_proposals.py` を実行すると提案CSVのみを生成する。
`measure.py` は手動起動時にMT5測定を開始する。今回の作成作業では実行しない。
再開・EA差し替え検知・スリープ抑止・端末回収・5400秒タイムアウトと
`blown` / `deals` 列を継承し、完了ログには `trades` を残す。

評価は幾何平均月利 `(最終資産 / 500000) ** (1 / 月数) - 1` と
直近ピーク比DDを使い、破綻フラグまたは最低資産が入金の20%未満の案を除外する。
損益はdealの `profit` のみ。決済損益曲線のDDは含み損を含まない下限値。
互換維持のため残す `monthly_pct` は算術平均で、複利の合否には使わない。

`adjudicate.py` は作成しない。ユーザー側で `ml/fxcomp1/adjudicate.py` を
流用する際は、参照先ROOT・基準ID（C001→R001）と旧3枠向け表示文言を合わせる。
背景・前ラウンドの結論は `docs/oanda_fx_compounding_20260909.md` を参照。
