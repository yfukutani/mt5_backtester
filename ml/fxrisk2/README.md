# FXRISK 第2ラウンド — SCAのrisk%化を実効化して測り直す

## なぜやり直すか

`ml/fxrisk1/` の88runは、**SCAのrisk%化が一度も効いていない状態**で測っていた。
`FxRiskOn()` は SCA枠に `useRisk=true` を立てるが、SCAの発注経路は `LotRisk()` を
通らず固定ロットを直接計算していたため、`FxRiskMask` の bit3/bit4 が無効だった。

実測の証拠は `ml/fxrisk1/results.csv` にある。FULL窓で
R008(mask=8) / R009(mask=16) / R016〜R021(mask=24) が、mask=0 の R003 と
純益 925,988円・最大DD 10.68%・取引数 2,969 まで完全一致する。
risk% を 0.25% から 1.0% へ4倍に振っても1円も動かない。

2026-09-15 に `experts/MIX_EA_SIMVERIFY.mq5` へ `ScaBaseLot()` を入れて修正した。
本ラウンドは**SCAが実際に risk% サイジングされる状態での初回測定**である。

## RSI枠は測り直さない

修正は SCA の発注経路にしか触れていない。mask が bit0〜2 のみの案
（fxrisk1 の A/B/C/H-RSI群）の結果はそのまま有効なので再測定しない。

S001 / S002 は「修正がSCA以外へ波及していないこと」の対照で、
それぞれ fxrisk1 の R003 / R013 と**完全一致しなければならない。**
一致しなければ修正が他へ波及しているので、そこで中断して原因を調べること。

## 提案

| family | 内容 | 案数 |
|---|---|---:|
| A | 対照（mask=0 / mask=7） | 2 |
| B | SCAを1枠ずつ（mask=8 / 16）× risk 0.05/0.1/0.25 | 6 |
| C | SCA 2枠（mask=24）× risk 0.05〜0.5 × fxref 2種 | 6 |
| D | RSI3＋SCA2（mask=31）非複利 | 4 |
| E | mask=31 を equity連動（fxref=0） | 3 |
| F | 9枠中8枠を equity連動（RefCap=0）＝最大複利 | 4 |
| G | 最大複利 × 倍率2・3 | 5 |

計30案・重複0件。枠別重みは全1.0。3枠のRefCapは常に同値。

## risk% の水準について

SCA GBPJPY は `scaBoostMult=6.0`（ドリフト逆行時のロット6倍）を持つ。
risk%化するとブースト取引の実効リスクは risk%×6 になるため、
fxrisk1 が使った 0.25〜1.0% では 1.5〜6% になり破綻側に振れやすい。
そのため **0.05% から並べている。**

## 窓と評価

入金500,000円・レバレッジ25・`every_tick`。
FULL = 2016.11.09〜2026.06.20（115か月）／OOS = 2016.11.09〜2021.06.20（55か月）。
30案×2窓＝60測定。各窓でS001を先に取得し、取引数が基準の半分未満なら
`blown=True`、判定不能なら空欄（破綻の暫定代理指標であり確定診断ではない）。

評価は幾何平均の月利（最終資産 ÷ 500000 の 1/月数 乗 − 1）と直近ピーク比DD。
`blown` または最低資産が入金の20%未満の案は候補から外す。
equity曲線は決済損益のみで作るため、**DDは下限値**で含み損を含まない。

## 実行

    python ml/fxrisk2/generate_proposals.py   # 提案CSVの生成のみ
    python ml/fxrisk2/measure.py              # MT5測定（直列・再開可能）
    python ml/fxrisk2/adjudicate.py           # 複利前提の評価

`measure.py` は fxrisk1 と違い、**案ごとにFULL→OOSを続けて測る。**
窓ごとの一括実行だと全FULLが終わるまで1案も両窓そろわず、途中経過から何も
判断できないため。所要は1案あたり約17分（実績中央値 FULL 741秒＋OOS 290秒）。

XM端末を使用・回収するため、他の掃引が終了してから起動すること。
背景と前ラウンドの結論は `docs/oanda_fx_risk_sizing_20260915.md`。
