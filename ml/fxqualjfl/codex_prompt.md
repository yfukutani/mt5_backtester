## 背景（2026-09-19 に実測で確定した、前提を覆す発見）

あなたは 2026-09-19 の棚卸し（`docs/codex_oafx_inventory_20260919.md`）で、
各軸に「±0.02pt以下だから価値が低い」という事前見込みを付けました。
**その数字はすべて「固定ロット」構成での実測に基づいていました。**

本日、全複利（risk%サイジング）構成の上で同じ EA 変更を測り直したところ、
**効き幅が固定ロットの 6.3〜155倍**になることが実測されました。

- `docs/oanda_fx_sleeve_quality_confirm_20260919.md`（採用候補2件: 12倍）
- `docs/oanda_fx_sleeve_quality_round10_20260919.md`
  （SCA USDJPY のレンジ幅下限: 固定ロット +3,991/+3,393 → 複利 **+150,369 / +525,131**。37倍/155倍）

機構は単純です。**risk%サイジングでは `ロット = リスク額 ÷ SL距離`** なので、
**SL距離が小さい取引ほど大きく賭ける**ことになります。
したがって「SL距離の分布」を変える施策は、損益を二重に動かします
（取引の採否 ＋ 残りの取引の重みづけ）。固定ロットでは後者が存在しませんでした。

さらに `docs/oanda_fx_compounding_attribution_20260919.md` で、
**複利では枠別損益がブックの分解にならない**ことも実測されました
（SCA GBPJPY を risk% から外すと、その枠自身は IS で +653,833 改善するのに、
 ブック全体は OOS −441,855 / IS −250,202 悪化した）。

## 今回お願いしたいこと

**「固定ロットでの効き幅が小さいから低価値」という理由で低く見積もった軸を、
複利レンズで並べ直してください。** 具体的には:

1. **9枠それぞれについて、「SL距離（＝ロットの分母）の分布を変える軸」を列挙してください。**
   - 各枠の SL がコード上どう決まるか（固定pips / ATR倍 / レンジ幅 / その他）を
     **EA の行番号付き**で示してください。`experts/MIX_EA_SIMVERIFY.mq5`
   - SL距離が**定数の枠**（例: 固定pips）は、この軸が存在しないと明記してください。
     存在しないなら「無い」と書いてください。
   - 存在する枠については、**下限・上限・変換（例: 分母をクリップする）**のどれが
     既存 input で表現できるか / EA 改修が要るかを分けてください。

2. **その上で、枠ごとに未測定の改良案を出してください（1枠あたり2〜4案）。**
   - **既に棄却された軸を繰り返さないこと。** `docs/rejected_strategies.md` を必ず参照し、
     「なぜこれが既存の棄却と別物か」を1行で書いてください。
   - 各案に **既存 input で表現できるか / EA 改修の規模**を付けてください。
   - 事前の見込みは、**固定ロットでの見込みと、複利での見込みを分けて**書いてください。
     楽観は不要です。**「複利でも小さい」と考えるならそう書いてください。**

3. **特に次の2つについて、あなたの見解を聞かせてください。**
   - (a) **SCA GBPJPY のレンジ幅下限**（`ScaFilMask` bit1・`ScaFilRangeMin`）。
     SCA USDJPY では両窓プラス・DDも低下でした。GBPJPY は複利で符号が反転する唯一の枠です
     （固定 FULL +115,992 → 複利 FULL −1,826,948）。同じ処方が効くと思いますか。
     ただし `ScaFilRangeMin` は**2枠で共有の1つの閾値**です。これは問題になりますか。
   - (b) **PB 2枠の SL は `atrSLmult=2.0` の ATR倍**（EA:1056行）です。
     つまり **ATR が小さい日ほど大きく賭ける**。これは SCA と同型の歪みですか。
     PB にレンジ幅下限に相当するものを入れるとしたら、何が正しい形ですか。
