# OANDA FX 月利6% — 証拠金律速を前提にした Claude 50案（2026-09-15）

`docs/oanda_fx_margin_efficiency_20260915.md`（第9報）の診断を前提にした案出し。
**Codex の50案は `docs/codex_oafx_margin50_20260915.md`**（別便）。

## 前提（第9報の診断）

- **cap の応答曲線は 60→100% で単調増加。折り返しが無い＝証拠金が律速している。**
- 実用域（cap90）の OOS窓中央値は **5.12%**。目標6%まで **1.17倍**。
- **RSI EURUSD が単独で証拠金日の 43.6%（OOSでは45.8%）を占める。**
  ピーク時は W1 100% / W2 91% / W8 90%。cap が削っているのは**その隣の枠**である。
- Carry は IS効率 最下位（−0.0061）・平均保有 **184.8日**。PB UJ は効率ほぼゼロで 6.2% を占有。
- **W4（全構成が負ける唯一の窓）は RSI 3枠が同時に負けて作られる。**
  そして W4 で2番目に稼いだのは **Carry**（外す候補）だった。

## 棄却済み（この50案には入れない）

銘柄の横展開 / 反対注文の相殺・通貨集中上限 / SCA の方向フィルタ・レンジ幅フィルタ /

# B. 証拠金の回転を上げる（10案）

# C. サイジングの作り直し（10案）

| # | 案 | なぜ効くか | 検証方法 | 見立て |
|---|---|---|---|---|
| **C1** | **証拠金あたりのリスクでサイジングする** — 今は「SL距離あたり equity の1%」。これを「**占有証拠金あたりの期待値**」に変える | 律速しているのが証拠金なら、**リスク予算ではなく証拠金予算で配るのが正しい** | MT5（EA改修・中） | **◎** |
| C2 | 空いた証拠金を `GlobalLotMult` で使い切る（倍率 4/5/6） | **検証中（E06/E07/E08）** | | ◎ |
| C3 | 倍率を**枠別**に上げる（効率の高い RSI GU・PB GJ・SCA GJ だけ） | **検証中（E14）** | | ○ |
| C4 | `GlobalLotMult` を**証拠金余裕率に連動**させる（余っていれば上げ、逼迫したら下げる） | 固定倍率は「常に同じだけ攻める」。余裕があるときに攻めないのは取りこぼし | MT5（EA改修・中） | ○ |
| C5 | equity ではなく **balance** でサイジングする | 含み損で equity が沈むと連鎖的にロットが縮む。balance なら安定するが**DDは深くなる** | MT5（既存入力で近似不可・改修小） | △ |
| C6 | 複利の基準を「直近N か月の最低equity」にする（保守的複利） | 急落直後に張りすぎるのを防ぐ。**月利は下がる方向** | MT5 | △ |
| C7 | risk% の対象を RSI 3枠（mask=7）から**全9枠**に広げる | 固定ロット枠が口座規模に連動する。**ただし過去ラウンドで mask=23 等は既に測って mask=7 に負けている** | MT5（既測の再確認のみ） | **△（見込み低い）** |
| C8 | ロットの丸め（`VOLUME_STEP`）で切り上げでなく切り捨て — **現状すでに切り捨て**（`MathFloor`） | 改善余地なし | — | **×** |
| C9 | 最小ロット 0.01 の下限に張り付いている枠を探す（`Clamp` が持ち上げている分は**リスク管理の外**） | 下限張り付きが多いなら、その枠は「サイジングされていない」。**測る価値はある** | deal ログ（MT5不要） | ○ |
| C10 | 口座を**枠グループごとに分割**して運用する（証拠金の取り合いを物理的に無くす） | 取り合いが問題なら分ければよい。**ただし1口座あたりの資金が減り複利が弱まる** | 段階2で計算可能 | △ |

## 優先順位（この50案のうち、次に回すもの）

1. **A5・D1**（MT5不要・deal ログだけで測れる）— 同時保有の分布と、RSI 3枠の相関
2. **C9**（MT5不要）— 最小ロットに張り付いている枠の洗い出し
3. **A3・A4・A6**（EA改修・小〜中）— 占有そのものを削る3つ
4. **E2・E4**（既存入力）— 証拠金を食わない枠の取引数を増やす
5. **B5・B8**（deal ログ＋MT5）— 滞留と週末跨ぎ

> [!warning] **見込みが低いと明示した案**: B3・B4・C7・C8・D7・D10・E7・E9・E10。
> このうち C8・E9・E10 は**実行不可または問いが変わる**ので測らない。

> [!danger] **50案のうち、単独で月利を 5.12% → 6% に押し上げる見込みのある案は無い。**
> どれも 0.1〜0.5pt の規模である。**1.17倍の差は、複数を積んで届くかどうかという水準。**
> 積んでも届かない可能性のほうが高いと考えている。
