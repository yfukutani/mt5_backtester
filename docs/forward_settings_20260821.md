# フォワードテスト用EAを実資金に合わせた設定へ変更（2026-08-21）

## 1. 変更の趣旨

フォワードテストの実口座残高に合わせてEAのリスク基準資金を明示指定した。
今後の方針は「最新EAをフォワードに適用し、その結果を見て構成を判断する」。

## 2. 実資金（2026-08-15時点・週次レポート実測）

|---|---:|---:|---:|
| OANDA FX 900282956 | 77,954 | 77,954 | 0 |
| OANDA CFD 900282957 | 102,183 | 102,183 | 0 |
| XM 370406351 | 52,366 | **117,366** | 65,000 |
| 合計 | 232,503 | 297,503 | 65,000 |

累計（テスト開始2026-07-06比）: equity 330,000 → 297,503 = **−32,497円 / −9.85%**
（クレジット65,000を除く実質元本265,000円比では **−12.26%**）

## 3. 変更内容

| EA | 設定 | 変更前 | 変更後 |
|---|---|---:|---:|
| MIX_EA（XM） | RefCap 3種 | 0（equity追従） | **117,000** |
| MIX_EA_OANDA | RefCap 3種 | 0（equity追従） | **78,000** |

`RefCap=0` のときEAは `AccountInfoDouble(ACCOUNT_EQUITY)` を毎回参照していた。
実額固定にしたことで、フォワード期間中にサイズが動かなくなり、バックテストとの
突合が正確になる。

倍率はすべて **x1のまま**。バックテストで確認した高倍率（x15等）は適用していない。

### 3.1 ユーザー判断による選択

- XMは**クレジット65,000を含むequity 117,000基準**（自己資金は52,366）。
  自己資金比では実質レバレッジが約2.2倍になる。クレジットは損失を吸収するが
  引き出せる資金ではない。
- 固定値のため**損失が続いてもロットは自動では縮まない**。残高が大きく動いた場合は
  値の見直しが必要。

OANDA CFD口座はGOLD 2枠のみでリスク建て枠を使わないため、この設定の影響を受けない。

## 5. 🚨 OANDA FX口座はDD30%を超過している

**OANDA FXは現在の資金77,954円に対し、IS 35.65% / 全期間 30.75% と両期間でDD上限を
超えている。** これは倍率を上げた結果ではなく、**全枠が最小ロット0.01の状態での値**である。

つまり **0.01が下限である以上、ロットを下げて解消することはできない。** 対処は次のいずれか:

1. **資金を増やす** — DD30%以内にするには IS基準で約 93,000円、全期間基準で約 80,000円必要。
   現状77,954円なので、IS基準なら約15,000円の追加が要る。
2. **枠を減らす** — 10枠のうち資本効率の低いものを止める。
3. **超過を許容して継続** — フォワードはDD耐性の実地確認が主目的（`forward_test_baseline.md`）
   でもあるため、意図的に許容する判断はありうる。

XM（21.97 / 22.43%）とOANDA CFD（11.48 / 8.50%）は30%以内に収まっている。

**この判断はユーザーに委ねる。** 本変更では設定を実資金に合わせるところまでを行い、
枠の停止や資金移動は行っていない。

## 6. 留意点

- 上記はバックテスト値。フォワードで同じDDに収まる保証はない。
- 直近の週次レポートで **8/14に3端末とも43時間停止**していた（watchdogが自動復旧）。
  フォワード結果を評価する際はこの不稼働期間を差し引いて見る必要がある。
- 現在フォワードは開始比 −9.85%。バックテストの想定月利（XM 8.13% / CFD 3.89%）とは
  乖離しているが、テスト期間が約6週間と短く、43時間の全断も含むため、
  この時点で結論を出すには早い。
