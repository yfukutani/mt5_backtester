# OANDA FX — Claude 50案（2026-09-17）

目標: **24か月窓を新規50万円口座として開始したときの月利（幾何平均）の OOS窓中央値 6%**。
制約: OANDA証券・**レバレッジ 1:25**・**FX 1注文あたり 10ロット**・入金50万円・`MarginCapPct≦90`（実用域）。

> [!important] **本リストの土台にしている構造（第8〜12報）**
> 1. **証拠金が律速**。注文だけで数えると通過率は **30.2%**（通期OOS・cap90）。
> 2. cap を 80→100 に 20pt 開けても通過率は 5.6pt しか動かない。
>    **効いているのは総量ではなく「通る取引の顔ぶれ」。**
> 3. `Mult_*` は cap を上回る領域では**何も変えない**（枠の定数倍だから）。
> 4. 入金を増やすと月利は**下がる**（天井に早く当たる）。
> 5. 倍率を上げると通期純益は増えるが**窓の中央値は下がる**。
> 6. Codex #1/#7（処理順・後追い補充）は上限 2.7%で**棄却済み**。

**見込みの分布を先に書く: 高 4件 / 中 13件 / 低 33件。**
**「高」でも単独で 6% を作る案は無い。** 全部当たっても届くとは限らない。

## 優先順位（測る順）

1. **#46** OANDA端末での再測定 — 他の全部の前提。ただし端末の切り替えが必要
2. **#1** 分割発注の可否（まず `SYMBOL_VOLUME_LIMIT` を実機で取る・run不要）
3. **#31** W2/W3 の枠別分解（run不要・既存 results.csv のみ）
4. **#8** RSI EU の証拠金予算（10/20/30/40%・4案×4窓＝16run）
5. **#4/#35** 利益引き出し（年1回・引き出し率3通り＝12run）
6. **#19/#30** 発注順の配分（逆順対照つき）
7. **#22/#23** Pair の縮小・停止（4案＝16run）

> [!danger] **正直な見立て: この50案のどれも、単独で「月利6%」を作らない。**
> 「高」を付けた4件のうち、**#1（分割発注）と #4（引き出し）は天井の問題を解くだけ**で、
> 天井が実は律速でなければ何も起きない。**#8 と #19 は顔ぶれを変える案**で、
> 顔ぶれを変える案は**窓ごとの当たり外れが大きく、第7報で2度「窓に切ったら消えた」を経験している。**
> **6%に届く道筋は、現時点でも見えていない。**
