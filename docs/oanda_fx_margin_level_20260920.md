**取引数 1179 → 1178 の正体も分かった**——

> [!important] **決定的なのは「最初の100建玉が完全一致」していることである。**
> 最初の食い違いは **2017-03-02**（窓開始から4か月）で、**それ以前は時刻・枠・ロット・価格まで完全一致。**
> **浮動小数の非決定性ならば最初から散らばるはずで、そうなっていない。**
> **cap が効き始めてから、cap に当たる注文だけがずれている。**
> → **テスターは決定的。差の原因は EA 差である。**

> [!danger] 🔴 **この帰属は不完全だった。交絡を1つ見落としていた（並行セッションの指摘で発覚）。**
>
> **`profit` 列を見ていなかった。** 約定の同一性を `time / magic / volume / price` だけで
> 判定していたので、**「同じ約定なのに損益だけが違う」＝スワップ差**が見えていなかった。
>
> **確かめたら、あった:**
>
> | | |
> |---|---|
> | 約定が完全一致している先頭区間 | **198行** |

> **MT5 テスターは「いまのスワップ率」を全履歴に一律適用する**ので、
> 業者がスワップを更新すると同じ設定でも損益が変わる
> ——**これは第19報（[Carry のスワップドリフト](oanda_fx_carry_swap_drift_20260919.md)）で

>

>

> > → cap 境界の注文のロットが1ステップ反転した（2017-03-02）
> > → 経路が分岐して複利で拡大した。**
>
> **「計装が cap 境界のロットを動かした」は、まだ示されていない。**
> **交絡（スワップ差）が実在し、単独でこの現象を説明できるからである。**
> **分離するには「同じ日・同じスワップで、計装の有無だけを変えた2本」が要る。**
> **並行セッションの `O000off`（計装OFF）と `O000`（計装ON）が同日なので、それで分離される。**
>
> **本日3度目の同じ型である**——既存の記録（第19報のスワップドリフト）を読まずに、
> **測っていない性質（計装が原因）を主張した。**

| net | 11,474,822 | **11,474,822** |
| pf | 1.2564 | **1.2564** |
| dd_pct | 36.2813 | **36.2813** |
| trades | 1245 | **1245** |

**1円も動かなかった。**

> **「計装が cap 境界の注文ロットを動かす」は棄却。計装は完全に受動的である。**
> **`M003` の MISMATCH も `fxoanda3` の +24.9% も、スワップ率のドリフトで説明がつく。**

**両セッションが独立に同じ誤帰属をし、両方とも交絡が原因だった。**

### 確定した規約（2点とも実測の裏づけあり）

1. **採否の比較は「同一バイナリ」かつ「同じスワップ・スナップショット（≒同じ日）」で揃える。**
   **cap 制約＋複利では、スワップ率の日次変動だけで OOS 純益が 25% 動く**（`fxoanda3` 対 `O000off`）。
2. **deal ログを突き合わせるときは必ず `profit` 列も見る。**
   `time / magic / volume / price` が一致しても同じ約定とは限らない。
   EA の `profit` は `DEAL_PROFIT + DEAL_SWAP + DEAL_COMMISSION`。

> [!important] **設計上の教訓（並行セッションの整理）:**
> **交絡を疑う対照を1本置いておくと、忘れていても救われる。**
> `O000off` が無ければ、`O000` の +24.9% を「計装のせい」で閉じていた。
> **「思い出す」に頼らず、対照で担保する。**

### ⚠️ 本ラウンドへの含意

**`ml/fxqual17` の16run は同一バイナリ・同じ晩なので、ラウンド内比較は有効。**
**`ml/fxqual14` 以前との純益比較は、スワップが違うので使えない。**
**幸い本報の主要な結論（維持率で誰が生き残るか）は16run 内で完結している。**

**判定: このラウンドは続行する。** 0.041% の差は**測ろうとしている量に影響しない**
（54.17% は 100% の境界から遠い）。

🔴 **ただし運用ルールを1つ足す:**

> **採否の比較は、必ず同一バイナリ同士で行う。計装入りと計装なしを混ぜて月利を比べてはいけない。**
> 扱っている効き幅が 0.01〜0.1pt なのに対し、**バイナリ差の系統誤差が 0.041% で同オーダー**である。
> **`fxqual17` の16run は全部同一バイナリなので、ラウンド内の比較は有効。**
> 期待値との MISMATCH は**「旧バイナリとの差」であって「測定の失敗」ではない。**
