## 3. なぜ効かないか — Boost 群への分解で機構が割れた

`ml/fxqual7/boost_split.py` で、Z000（対照）と Z001（1.0R 建値）を
**リバーサル増し玉（RevBoost）の有無**で割った（判別はロット・GBPJPY は 0.01 / 0.06）。

| 枠 | 群 | 窓 | Z000 | Z001 | **差** |
|---|---|---|---:|---:|---:|
| **SCA GBPJPY** | **Boost** | OOS | +57,804 | +49,596 | **−8,208** |
| | | IS | +69,492 | +59,316 | **−10,176** |
| SCA GBPJPY | plain | OOS | −15,585 | −15,642 | −57 |
| | | IS | +4,281 | −638 | −4,919 |
| SCA USDJPY | Boost | OOS | −2,963 | −2,351 | **+612** |
| | | IS | +14,886 | +15,534 | +648 |
| SCA USDJPY | plain | OOS | +739 | +851 | +112 |
| | | IS | +3,677 | +3,342 | −335 |

**SCA GBPJPY の損失の大半（OOS −8,208 / IS −10,176）は Boost 群から出ている。**
そして **Boost 群こそが、この枠の利益のすべてを稼いでいる群**である
（対照で OOS +57,804 / IS +69,492 に対し、plain は −15,585 / +4,281）。

> [!important] **建値ストップは、この枠で「利益を出している当の取引」の伸びを切っていた。**
> リバーサル型（レンジ内で逆方向にドリフトした日に6倍で入る）は、
> **入った後に大きく伸びる**から6倍の価値がある。
> 建値に寄せると、その伸びの途中の押し戻しで刈られる。
>
> 逆に **SCA USDJPY では Boost 群が OOS で赤字**（−2,963）なので、
> 建値ストップは**わずかに助ける**（+612）。
> **同じ機構が、枠によって符号が逆になるのは「Boost 群が儲かっているかどうか」で決まる。**

これは、並行セッションが `ml/fxqual8` で測っている
**「リバーサル条件を入口ゲートにする」**案の裏返しの証拠でもある。
**この枠の値打ちは全部リバーサル群にあり、それを退出側で削ると枠が壊れる。**

## 4. 予想の照合

| 予想 | 結果 |
|---|---|
| 「両窓でプラスになる確率は高くない」 | **当たり**（7案中プラスは Z007 の OOS だけ） |
| 「**Z002（0.5R）が最も悪い**と予想する」 | **外れ。** 最悪は **Z004（1.0R で建値+0.5R・IS −30,108）**で、Z002 は唯一プラスの窓を持つ |
| 「Boost 群の伸びを切ると枠が壊れる」 | **当たり**（§3） |

**0.5R が最悪という読み**（当方と並行セッションが一致していた）は、
「ORB の初動はレンジ上端の攻防を往復するので、0.5R は勝負がつく前に切る」という理屈だった。
**実測ではそうならなかった。** 0.5R は早く建値に寄せるぶん**発火が早く**、
**伸びる前に刈るのではなく、伸びなかった取引を早く諦める**側に働いたと読める
（IS で +2,786・GJ が 73,773→79,222）。**ただし OOS は −7,056 なので採らない。**

> [!warning] **「建値より上にロックする」（Z004・Z005）は、素の建値より一貫して悪い。**
> Z004 は **IS −30,108（月利 0.852%→0.751%）**でこのラウンド最悪。
> 利益を固定しにいくほど、Boost 群の伸びを深く切る。**この方向は完全に閉じる。**

## 5. 確定した棄却

| 軸 | 判定 |
|---|---|
| **SCA 2枠の建値ストップ（全水準）** | **棄却。** 1.0R も 1.5R も両窓マイナス、0.5R は割れる |
| **建値より上へのロック（Z004・Z005）** | **棄却。** 素の建値より一貫して悪い |
| **SCA GBPJPY の退出側の後付け一般** | **閉じる。** 損失は Boost 群＝利益源そのものから出る |

### SCA USDJPY 単独（Z007）は両窓プラスだが、採らない

**OOS +732 / IS +327**。形式的には**両窓改善**である。機構の説明もつく——
**SCA USDJPY の Boost 群は OOS で赤字**（−2,963）なので、その伸びを切っても失うものが無い。

**それでも採らない。理由は3つ。**

1. **効き幅が月利 +0.003pt（OOS）/ +0.001pt（IS）。** 採用の可否を論じる水準に無い。
2. **結果を見てから枠を選んだ形である。** Z001（2枠）が両窓マイナスと分かった後で
   「どちらの枠が悪さをしているか」を分解し、良かったほうだけを残している。
   これは第16報の V007 が示した失敗と**同じ構造**である。
   （`ml/fxqual6` の slope は**台地が5点連続**だったので採用候補にしたが、
     ここは**2枠のうち片方**であり、台地に相当するものが無い。）
3. **根拠が「その枠の Boost 群が赤字だから」であり、それは窓依存である。**
   SCA USDJPY の Boost 群は **OOS −2,963 / IS +14,886 と符号が反転している。**
   OOS で助けたのは、たまたま OOS で Boost が赤字だったからにすぎない。
