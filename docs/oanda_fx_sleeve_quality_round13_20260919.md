# 第13ラウンド `ml/fxqual13` — RSI 3枠の機構別 TP（棚卸しの最後の未測定軸・設計と事前予想）

## 0. これで棚卸しがゼロになる

Codex の棚卸し（[inventory](codex_oafx_inventory_20260919.md)）が「未実装・未測定」として
残した3軸のうち、**SCA の2つは第12ラウンドで閉じた**（12案すべて棄却）。
**残るのは「RSI 3枠の機構別退出」だけ**である。

現行は **R（RSI 反転）/ B（BB 回帰）/ D（ダブルトップ・ボトム）の3機構が OR で入口に同居**し、
**退出は共通の固定 TP ひとつ**しか持っていない。
**「BB 回帰で入った玉と、ダブルボトムで入った玉が、同じ距離で利確する理由は無い」**が動機である。

## 1. EA への追加（既定 0 で完全に inert）

| input | 内容 |
|---|---|
| `RsiTpMask_UJ` / `_EU` / `_GU` | **組み合わせコードのビットマスク**（`RsiMechMask_*` と同じ規約）。0 で無効 |
| `RsiTpMult_UJ` / `_EU` / `_GU` | マスクに当たったコードで発火した玉だけ、TP を何倍にするか |

コード ＝ `(R?1:0) | (B?2:0) | (D?4:0)`、マスク ＝ `OR(1 << (コード-1))`。
例: D を含む全部（4,5,6,7）＝ **120** / B 単独 ＝ **2** / RB 同時 ＝ **4** / 全部 ＝ **127**。

実装は `RsiTpFactor()` 1関数と、`ProcRSI` の発注2箇所で `tpd` を `tpdB` / `tpdS` に差し替えただけ。

> [!important] **第1段階は TP だけ。SL は触らない。**
> Codex の助言に従った。**SL を動かすと `risk%` の分母（`lot = リスク額 ÷ SL距離`）が変わる**ので、
> **「退出設計の効果」と「1取引の重みづけの変化」が混ざって因果が読めなくなる。**
> SL 固定なら、変わるのは**勝率と実現RR だけ**である。

### 5.2 🟢 **錨が仕事をした — 「機構別」は本物だった**

各枠で「**狙った群だけ ×1.5**」と「**全コード ×1.5**」を並べた。**3枠すべてで、
狙い撃ちのほうが OOS で 0.14〜0.16pt 良い:**

| 枠 | 狙い撃ち（OOS） | 全コード（OOS） | **差** |
|---|---:|---:|---:|
| USDJPY | `T001` **+0.011pt** | `T004` −0.127pt | **+0.138pt** |
| GBPUSD | `T005` −0.031pt | `T007` −0.179pt | **+0.148pt** |
| EURUSD | `T008` **+0.039pt** | `T010` −0.123pt | **+0.162pt** |

> [!important] **3つの独立な枠で、差がほぼ同じ大きさ（+0.14〜0.16pt）で出た。**
> **「TP を伸ばすと良くなった」のではない——伸ばす対象を間違えると必ず悪くなる。**
> **これは「機構別退出」という軸が、このブックで実体を持つことの直接の証拠である。**
>
> 特に USDJPY は構造がきれいに割れた。`RsiMechMask_UJ=124` が許すコードは 3,4,5,6,7 で、
> `T001`（D を含む 4,5,6,7）と `T004`（全部）の差は **コード3（RB 同時）だけ**である。
> **RB の TP を 1.5倍にすると、それだけで OOS が −0.138pt 動く。**
> 逆に 0.7倍（`T003`）も −0.016pt。**RB の TP は現行がほぼ最適で、伸ばすのが明確に悪い。**
> **「D を含む群は伸ばしたい、RB は伸ばしたくない」——狙っていたとおりの分離が出た。**

**IS 優先の既定方針とも衝突しない**（IS も改善しているので、トレードオフですらない）。

**`T008`（EU・B 単独 ×1.5）は保留。** 損益は両窓プラス（+0.039 / +0.032pt）で
**このラウンド最大の OOS 改善**だが、**OOS の equity DD が 34.57% → 36.67% と +2.10pt 悪化する。**
第16報の「EURUSD は入口が窓に対して不安定」という評価もあるので、**単独では採らない。**

**`T005`（GU・B 単独 ×1.5）は棄却。** IS は **+0.075pt**（このラウンド最大の IS 改善）で
IS の DD も下がるが、**OOS が −0.031pt・OOS の DD が +1.36pt 悪化する。**

**`T002` / `T006` / `T009`（TP を縮める側）は3枠とも棄却。**
OOS は3点ともマイナス（−0.038 / −0.088 / −0.046pt）。**縮める方向に用は無い。**

### 5.4 事前予想の答え合わせ（2勝2敗）

- ✅ **「上振れ候補は `T001` だけ、それでも ±0.05pt」的中**（実測 +0.011 / +0.015pt）。
  **枠別純益から母数を見積もる**という第12ラウンドの学びが機能した
  （RSI 3枠は OOS でブックの 11% しかないので大きくなりようがない、と書いた）。
- ✅ **「GBPUSD は主戦力をいじると悪化」は OOS で的中**（−0.031pt・DD +1.36pt）。
- 🔴 **「本ラウンドも IS はほぼ全点マイナス」は外れた。** **10案中7案で IS がプラス**である
  （第12ラウンドは12案中10案がマイナスだった）。
  **「いまの構成は IS について局所最適」という第24報の読みは、退出側には当てはまらない。**
  **入口（重み・ゲート）は動かす余地が無く、退出（TP）にはまだ余地がある**——
  **これは第12ラウンドの結論の範囲を狭める訂正である。**
- 🔴 **「EURUSD は不安定なので両窓ばらばら」は外れた。** `T008` は**両窓プラス**だった。
  ただし**OOS の equity DD が +2.10pt 悪化**しているので、不安定さは DD 側に出ている。
