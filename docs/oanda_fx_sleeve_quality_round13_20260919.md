## 0. これで棚卸しがゼロになる

Codex の棚卸し（[inventory](codex_oafx_inventory_20260919.md)）が「未実装・未測定」として
残した3軸のうち、**SCA の2つは第12ラウンドで閉じた**（12案すべて棄却）。
**残るのは「RSI 3枠の機構別退出」だけ**である。

現行は **R（RSI 反転）/ B（BB 回帰）/ D（ダブルトップ・ボトム）の3機構が OR で入口に同居**し、
**退出は共通の固定 TP ひとつ**しか持っていない。
**「BB 回帰で入った玉と、ダブルボトムで入った玉が、同じ距離で利確する理由は無い」**が動機である。

## 1. EA への追加（既定 0 で完全に inert）

| input | 内容 |
|---|---|
| `RsiTpMask_UJ` / `_EU` / `_GU` | **組み合わせコードのビットマスク**（`RsiMechMask_*` と同じ規約）。0 で無効 |
| `RsiTpMult_UJ` / `_EU` / `_GU` | マスクに当たったコードで発火した玉だけ、TP を何倍にするか |

コード ＝ `(R?1:0) | (B?2:0) | (D?4:0)`、マスク ＝ `OR(1 << (コード-1))`。
例: D を含む全部（4,5,6,7）＝ **120** / B 単独 ＝ **2** / RB 同時 ＝ **4** / 全部 ＝ **127**。

実装は `RsiTpFactor()` 1関数と、`ProcRSI` の発注2箇所で `tpd` を `tpdB` / `tpdS` に差し替えただけ。

> [!important] **第1段階は TP だけ。SL は触らない。**
> Codex の助言に従った。**SL を動かすと `risk%` の分母（`lot = リスク額 ÷ SL距離`）が変わる**ので、
> **「退出設計の効果」と「1取引の重みづけの変化」が混ざって因果が読めなくなる。**
> SL 固定なら、変わるのは**勝率と実現RR だけ**である。

> [!warning] **錨（全コード）が要である。**
> これが無いと、**「機構別にしたから効いた」のか「単にこの枠の TP を伸ばしたから効いた」のか
> 分離できない。** 第12ラウンドの overshoot 群では、緩い側の点を錨として置いたおかげで
> 「OOS はほぼ 0」が確認できた。同じ作法を枠ごとに敷く。

**今回は `CAP_LOG=True` を立てた。** 第12ラウンドは立て忘れて equity DD を落とした。
**OOS では equity DD が残高DD より 11〜16pt 大きい**ので、残高DD だけでは採否を論じられない。

## 3. 事前の予想 — **低い。上振れ候補は1つだけ**

- **Codex の査読は「0.00pt 中心・定量幅なし」**（[codex round12](codex_oafx_round12_20260919.md)）。
- **第12ラウンドは12案中10案で IS が悪化した。**
  「いまの構成は IS について局所最適に座っている」と書いた。
  **本ラウンドも IS はほぼ全点マイナスになると予想する。**

| 枠 | 第16報で分かっていること | 予想 |
|---|---|---|
| **RSI USDJPY** | **D を含む足で勝ち、B 単独で負ける（両窓同符号）**。採用済みの `RsiMechMask_UJ=124` が既に R単独・B単独を落としている | **`T001`（勝っている群の TP を伸ばす）が唯一まともな上振れ候補。それでも ±0.05pt** |
| **RSI GBPUSD** | **B 単独が主戦力で、落とすものが無い** | 主戦力の TP をいじる＝枠の性格そのものを変える。**両方向とも悪化** |
| **RSI EURUSD** | **B と RB が両方とも符号反転＝入口が窓に対して不安定** | **不安定な入口の退出を最適化しても、その不安定さを増幅するだけ。両窓ばらばら** |

**第12ラウンドで1つ学んだことを、ここに効かせる:**
「rr を上げてもほぼ 0」という予想が SCA GBPJPY で外れたのは、
**発火率（6〜7%）だけを見てその群の金額（110〜157万円）を見なかったから**だった。
**今回は「その群がいくら持っているか」で母数を見積もる。**
`ml/fxqualexec` の E000 の枠純益は **rsi_uj +54,494 / +298,458・rsi_gu +103,360 / +206,436・
rsi_eu +3,163 / +319,501**（OOS / IS）。**RSI 3枠合わせても OOS はブックの 11%** しかない。
**したがって OOS 側の効き幅は、そもそも大きくなりようがない。**
