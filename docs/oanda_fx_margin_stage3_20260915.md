>
> 発見は Codex の査読による。詳細と修正:
> [oanda_fx_leverage_bug_20260915.md](oanda_fx_leverage_bug_20260915.md)。

**`MarginCapPct` を 80% / 85% に設定した MT5 バックテストが、cap を掛けない run と
純益・最大DD・取引数まで完全に一致した。cap は発注時に一度も発動していない。**

**段階2の証拠金再構成は約10倍過大だった。**
そのため「実行可能な最良は T043 の OOS 2.26%/月」という
[oanda_fx_fxrisk3_final_20260915.md](oanda_fx_fxrisk3_final_20260915.md) §3① の結論は**無効**。

月利は幾何平均の複利、最大DDは最大相対DD（残高ベース）。

| U000 | 〃 | 0 | FULL | 17,072,185 | 3.14% | 40.06% | 2,969 |

## 2. 「効いていない」のか「配線されていない」のか — 切り分け

| 疑い | 確認 | 結果 |

  **T030（mask=31・risk1%・倍率3）**の run である。T030 の取引数が
  FULL 2,964 / OOS 1,371 と、他案の 2,969 / 1,375 より少ないのはこの拒否によるもの。

## 3. 段階2の再構成が間違っていた理由 — 符号が逆だった

`ml/fxrisk3/margin_feasibility.py` は T036 の証拠金使用率を **988.3%**、
100%超の時点を **693/2,750回** と出していた。最悪点は 2021-02-12、
使用証拠金 4,398,958円 に対し equity 445,091円。

このスクリプトは equity を **決済損益のみ**（`DEPOSIT + 確定利益`）で作っている。
docのただし書きは「**含み損を含まないので実際の維持率はここより悪い**」だった。
**これが逆だった。**

このブックは **Carry AUDJPY と PB GBPJPY が数か月級でポジションを持ち続ける**。
2021-02 の時点で口座は大きな**含み益**を抱えており、MT5 が証拠金判定に使う
`ACCOUNT_EQUITY`（＝残高＋評価損益）は、再構成の 445,091円 よりはるかに大きかった。
トレンド／キャリー型の枠を含むブックでは、決済ベース equity は**下振れ側に偏る**。

裏づけとして、T030 だけは実際に `[No money]` で弾かれている。
**テスターは証拠金を確かに執行している**——T036 がその下に収まっていただけである。

> [!note] レバレッジ25の適用そのものは間接確認にとどまる
> ini の `Leverage=25` は渡っているが、シンボル側の margin_initial が
> これを上書きしていないことは直接には確認していない。
> ただし T030 が 2021-05-13 に **GBPJPY 7.43ロット**（1:25 なら必要証拠金 約458万円）で
> 弾かれ、同時期の小さいロットは通っているという挙動は 1:25 と整合する。

## 4. 何が無効になり、何が残るか

### 無効になったもの

- fxrisk3最終docの §3①「**OOS幾何平均（証拠金100%超ゼロ）= 2.26%（T043）・6%まで2.7倍**」
- 同 §4 の推奨 T043 を「**実行可能な唯一の選択肢**」とした根拠
- 同 §1 の表の「証拠金OOS」「100%超」の2列すべて
- 「制約はDDではなくレバレッジ25の証拠金だった」（§3②）——**制約ではなかった**
- A10 を**サイジング規則**として使う道（[oanda_fx_margin_cap_20260915.md](oanda_fx_margin_cap_20260915.md)）。
  段階2で「cap80% で OOS 5.01%/月」としたのは、過大な証拠金を前提にロットを削った結果であり、
  **実機では削るべきロットが存在しない**。A10 は**レバーとしても制約としても死んだ**。

### 残るもの

**頑健性の問題は1つも解決していない。** T036 は実行可能だが、推奨できない：

| 指標 | T036（実行可能・最良） | T043（旧推奨） | 本番現行 |
|---|---:|---:|---:|
| 損益（OOS 55か月） | 6,431,197円 | 1,213,378円 | 119,537円 |
| 損益（FULL 115か月） | 271,741,303円 | 17,072,185円 | 379,084円 |
| **想定月利（OOS）** | **4.90%** | 2.26% | 0.39% |
| 想定月利（FULL） | 5.63% | 3.14% | 0.49% |
| 月利の中央値（OOS） | 1.80% | 1.40% | 0.10% |
| **上位3か月を除いた幾何平均（OOS）** | **−0.10%** | 0.80% | 0.16% |
| **最大DD（OOS / FULL）** | **85.4% / 89.5%** | 29.5% / 40.1% | 5.2% / 5.6% |
| 最低資産 | **444,704円（元本割れ）** | 500,000円 | 500,000円 |

**T036 の OOS 4.90% は、55か月のうち上位3か月が作っている。** それを除くとマイナスになる。
24か月窓に切った評価（[oanda_fx_cap_pathdep_20260915.md](oanda_fx_cap_pathdep_20260915.md)）でも
T036 の月利中央値は 4.73% で、**倍率2の T035（5.70%）に負ける**。

## 5. 目標6%に対する現在地

| 指標 | 最良 | 6%まで |
|---|---:|---|
| OOS幾何平均（MT5実測・実行可能） | **4.90%（T036）** | **1.2倍** |
| 同・24か月窓の中央値 | 5.70%（T035・段階2） | 1.1倍 |
| OOS・上位3か月を除いた幾何平均 | 1.33%（T039） | 4.5倍 |

**ヘッドラインの距離は 2.7倍 → 1.2倍 に縮んだ。ただし縮んだのは測り方の誤りを直した分であって、
成績が良くなったわけではない。** T036 の実力は最初から 4.90% だった。

**裾を除いた実力（上位3か月除外 1.33%）では、6%まで依然として 4.5倍ある。**
ここが本当の距離であり、今日の発見はこの数字を1ミリも動かしていない。
