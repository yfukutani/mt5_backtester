## 2. 分かったこと

1. 🔴 **事前予想は外れた。** 「cap70 は落ちる」→ 3窓とも完走。「完走域の中央値は 2〜3%」→ cap50 で 4.95%、cap70 で 6.57%。
   **予想は捨てる。** OANDA 端末・上限10ロット・1:25 で、E04＋cap50 は 55か月を **5.54%/月** で走り切った。
2. **XM の同構成（`ml/fxvmax1` O004: E04＋上限10・cap100）は通期OOS 7.79%・W中央値 8.66%。**
   OANDA 端末＋cap50 では **通期で −29%・中央値で −43%**。第14報の「フィード差 −27%」と同じ桁だが、
   cap も 100→50 に落としているので、**フィード差と cap の寄与は分離できていない。**
3. **cap を上げるほど月利も残高DD も上がる**（33→50→70 で W3 が 1.59→3.72→4.45%、DD 38→46→58%）。
   S070 は W3 の残高DD 57.8% で、**含み損込みの equity DD は未測定**（テスター側の中間ファイルが
   S033 W2 の 27.81% しか残っていない）。**OANDA の 100% ロスカットに対してどれだけ余裕があったかは、この数字からは分からない。**
4. **IS 窓（2021-06〜2026-06）は一度も測っていない。** 全複利ブックの RSI 3枠は IS で最も弱い枠
   （XM 15枠の枠別表で IS +7,440〜+13,286円）なので、**RSI に 3% を集中させる T036 系は IS で崩れる可能性がある。**
   ユーザー方針は「トレードオフでは IS を優先」なので、**IS を測るまで採用候補にはできない。**
