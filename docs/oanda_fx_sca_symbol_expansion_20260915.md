# SCA の新銘柄横展開 — 5銘柄すべて棄却。CADJPYも単年依存で実質ゼロ（2026-09-15）

**結論: 全銘柄を棄却する。**
CADJPY は5銘柄で唯一「両窓で黒字」を満たしたが、**OOS の寄与は月 0.033%**（6%への距離の1/90）で、
しかも**2020年を除くと4年半で +207円**——経済的にはゼロだった。
EURJPY / AUDJPY は IS だけ黒字で OOS は赤字（IS適合）。CHFJPY / NZDJPY は両窓とも赤字。

`ml/scanew1/` の112run（56案×2窓・うち2run失敗）は 2026-09-11 に測定済みだったが
**ドキュメント化されていなかった。** 今回の100案ラウンドで Claude案 C1/C2/C3/C5
（SCAをEURJPY / AUDJPY / ドルストレート / JPYクロスへ展開）に直接答えるため、
記録として残す。

## 1. 何を測ったか

SCA（アジア時間のレンジをロンドンオープンで抜ける）は現在 GOLD / USDJPY / GBPJPY の
3銘柄でしか使っていない。同じ構造は他のJPYクロスにもあるはずで、**新しい収益源**に
なりうる——という仮説。

`experts/MIX_EA_SIMVERIFY.mq5` の `ScaNewEnable` ラボ（既定OFF）で、
**1銘柄ずつ**有効にして測った（同時に複数を有効にすると寄与が分離できない）。

| 群 | 内容 | 案数 |
|---|---|---:|
| S0 | 新枠OFF（既存9枠の基準） | 1 |
| S1 | 5銘柄 × USDJPY親枠の既定形 | 5 |
| S2 | `ScaNewRangeEnd` 7 / 11 | 10 |
| S3 | `ScaNewTradeEnd` の振り | 10 |
| S4 | `ScaNewRR` 1.5 / 3.0 | 10 |
| S5 | `ScaNewMinRange` / `MaxRange` の振り | 10 |
| S6 | `ScaNewBoostMult` の振り | 10 |

銘柄は **EURJPY / AUDJPY / CADJPY / CHFJPY / NZDJPY**。
入金 500,000円・レバレッジ25・`every_tick`・**固定ロット0.01**。
窓は **IS = 2021.06.21〜2026.06.20（60か月）/ OOS = 2016.11.09〜2021.06.20（55か月）。**

> [!note] この窓の取り方は fxcomp1 / fxrisk1 の FULL/OOS とは違う。
> scanew1 は IS（直近5年）と OOS（それ以前）に分けている。比較時は注意。

このハーネスは「最良年を除外した純益」も出している。CADJPY の上位案はすべて、

**N032 の OOS は、2020年を除くと 4年半で +207円。** 経済的にはゼロである。
N004 と N031 は最良年を除くと**赤字に転落**する。

「両窓で黒字」という第一判定を通ったのは、**IS の2022年と OOS の2020年という
別々の単年**がそれぞれ全体を持ち上げていたからで、**持続的な優位性の証拠ではない。**

### 最大DDについて

新枠単独のDDはこのハーネスでは分離して出していない（既存9枠との合成でしか意味がないため）。
参考として、基準 N001（新枠OFF）のブック全体は **純益 +257,817円 / 円建てDD 48,728円**
（入金比 9.7%）。新枠を1つ足しても取引数・損益規模の変化は小さく、
**DDの水準を動かすほどの規模ではない。**
なお円建てDDは deal の確定損益の累積から計算しており、**含み損を含まない下限値**である。

## 4. なぜ採用しないか

月利6%への距離は、現時点の最良構成（OOS 3.02%）からでも **2.98ポイント**ある。

| | OOS寄与 | 2.98ポイントに対して |
|---|---:|---|
| SCA CADJPY 追加（N032・固定ロット） | **+0.033%/月** | **1/90** |
| 参考：RSI 3枠の risk%化 | +0.26%/月 | 1/11 |
| 参考：RefCap 78,000 → 250,000・倍率3 | +1.34%/月 | 1/2.2 |

**桁が2つ足りない。** 仮に risk%化・複利化して規模を10倍にできたとしても +0.33%/月で、
目標への寄与としては小さい。既存 SCA GBPJPY（FULL純益 115,992円）の**1/13の規模**しかない。

横展開の実績が悪いという事前の見立て（PBは SILVER / JP225 / NASDAQ / 原油 /
NZDUSD / USDCAD がすべて棄却）とも整合する。**SCAも例外ではなかった。**

そのうえ、**その 0.033% すら単年に依存している**（上記のとおり2020年を除くと +207円）。
「両窓で黒字」を通ったのは、IS の2022年と OOS の2020年という**別々の単年**が
それぞれ全体を持ち上げていたからで、**持続的な優位性ではない。**

> [!note] 記録として残す価値があるのは「棄却した」という事実のほう。
> 5銘柄すべてを測って、**SCA に横展開の余地が無いことを確定させた**のが本ラウンドの成果である。
> 将来また「SCAを他のJPYクロスへ」という案が出たときに、この記録で止められる。
