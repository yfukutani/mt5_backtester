# 口座50万円の適切な倍率と月利 — XM版 / OANDA版を分けて再測定（2026-09-05）

**結論（先に）**

- **同じリスクなら XM構成が約26%有利。** 暗号3枠がGOLD一極集中を緩和し、月利を押し上げる。
  OANDAには暗号CFDの取扱が無いため**構造的に再現できない**。
- **月利6%は、入金50万でDDを守りながらは届かない。** 6%に必要な倍率は
  XMで x6（入金比の落ち込み38.7%）、OANDAで x8（同50.6%）。
- **DD30%を入金額に対して守るなら上限は両者とも x4。**
  そのとき全期間月利は XM 4.08% / OANDA CFD 3.24%。

# 第3部　比較と推奨

## 3.1 同じリスクで比べる（入金50万に対する落ち込みを揃える）

| 入金比の落ち込み | XM構成 | 倍率 | 全期間月利 | OANDA CFD | 倍率 | 全期間月利 | XMの優位 |
|---:|---|---:|---:|---|---:|---:|---:|
| 約19% | XM 5枠 | x3 | 3.06% | GOLD 2枠 | x3 | 2.43% | **+26%** |
| 約25% | XM 5枠 | x4 | 4.08% | GOLD 2枠 | x4 | 3.24% | **+26%** |
| 約32% | XM 5枠 | x5 | 5.10% | GOLD 2枠 | x5 | 4.05% | **+26%** |
| 約51% | XM 5枠 | x8 | 8.16% | GOLD 2枠 | x8 | 6.47% | **+26%** |

**倍率あたりの円建てリスクは両者ほぼ同一**（x5で 32.2% 対 31.6%）で、
**リターンだけXMが一貫して約26%高い。** 差は暗号3枠ぶんである。

## 3.2 推奨パラメータ（DD30%を入金額に対して守る場合）

### XM構成を選ぶなら

```
Mult_PB_GOLD  = 4.0
Mult_SCA_GOLD = 4.0
Mult_ETH      = 4.0
Mult_BTC_FUND = 4.0
Mult_BFXREV   = 4.0
```
→ 全期間 月利 **4.08%** / IS 月利 6.52% / 入金比の最悪落ち込み **25.8%**

### OANDA構成を選ぶなら（CFD口座単独・FXは使わない）

```
Mult_PB_GOLD  = 4.0
Mult_SCA_GOLD = 4.0
```
→ 全期間 月利 **3.24%** / IS 月利 5.57% / 入金比の最悪落ち込み **25.3%**

## 3.3 月利6%を狙う場合に必要な倍率

| 構成 | 必要倍率(全期間) | そのときの入金比落ち込み | 最悪1取引の入金比 |
|---|---:|---:|---:|
| XM 5枠 | **x6** | **38.7%** | 22.8% |
| OANDA CFD | **x8** | **51.6%** | 30.4% |

**どちらもDD30%を大きく超える。** 入金50万で月利6%とDD30%は両立しない。
達成するには資金を増やすか、枠を増やして資本効率を上げるしかない。

## 3.4 ⚠️ MT5の最大相対DD%を倍率選択に使ってはいけない

このEA群はロット固定なので円建ての損失額は期間によらずほぼ一定だが、
残高は10年で入金の7〜13倍に膨らむ。MT5の最大相対DD%は**その時点の残高に対する比率**
なので、後半に起きた落ち込みほど%が小さく出る。

実測では最大の落ち込みは XM で 2024-09、OANDA CFD で 2026-03 に発生し、
そのとき残高は既に 100万〜620万円まで増えていた。

| 例 | MT5が示すDD% | 入金50万に対する実際の落ち込み |
|---|---:|---:|
| XM x15 | 32.63% | **96.7%** |
| OANDA CFD x15 | 20.75% | **94.8%** |
| OANDA CFD x8 | 12.16% | **50.6%** |

**倍率はMT5のDD%ではなく、入金額に対する円建ての落ち込みで判断すること。**

## 3.5 その他の留意点

1. **すべてバックテスト。** フォワードは 2026-07-06 開始で現在 −13.11%（8週）。
   主因は GOLD の過大リスク（A-1）で、PB GOLD 1件 −11,365円・
   SCA GOLD リバーサルBoost 1件 −10,704円が半分を占める。x4 にすればこれらも4倍になる。
2. **GOLD 2枠は分散が無い。** OANDA CFDは全期間630取引・月5.5回。XMは暗号3枠が入って
   748取引・月6.5回だが、それでも薄い。
3. **XMの優位は暗号3枠に依存する。** 暗号の地合いが変われば差は縮む。
   XM GOLD単体（x5全期間3.97%）は OANDA CFD（x5 4.05%）とほぼ同じで、
   **GOLD部分そのものに差は無い。**
4. **法規制上の懸念**を重視するならOANDAだが、月利は約26%落ちる。
