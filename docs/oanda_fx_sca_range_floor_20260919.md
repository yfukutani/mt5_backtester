## 1. OOS の利得は、まるごと「この枠を止めること」である

**floor 0.0150 の OOS Δ（+149,604）は、枠を丸ごと外した値と1円まで同じ**である（どちらも n=0）。
そして **0.0048 以降の OOS Δ は +108,616 〜 +159,255 の範囲で振れているだけ**で、
**取引数は 103 → 49 → 31 → 19 → 9 → 1 → 0** と消えていく。

> **OOS では「閾値」は何も足していない。「この枠を OOS で止める」ことが利得のすべてである。**
> 0.0048 以降の上下は、**1〜31取引のノイズ**である。

## 2. IS では閾値が本当に効いている

**IS は 0.0042〜0.0060 で頂上（+409,131 〜 +525,131）、0.0150 で −50,148、∞ で −48,828。**
**枠を外すのは IS では明確な損**であり、**閾値だけが「広いレンジを残して狭いものを落とす」**
という仕事をしている。

## 3. ⚠️ 0.0060 は尖りである。採るのは 0.0042〜0.0048

| floor | IS Δ | 隣との差 |

| 0.0048 | +409,131 | — |
| **0.0060** | **+525,131** | **両隣より +116,000 / +248,000 高い** |

**前後より 11〜25万円高い単独の突出**で、`ml/fxqual6` で「採ってはいけない」と定めた**尖り**の形である。

**対して 0.0042 と 0.0048 は、隣り合った2点が +413,234 / +409,131 とほぼ同値**であり、
**取引数も 245 / 214 とこの帯で最大**である。**これが台地の内側である。**

> [!important] **採用値: `ScaFilRangeMin = 0.0048`（`ScaFilMask = 1`）。**
> OOS +150,369（幾何月利 2.337% → **2.488%**・DD 28.47% → **23.45%**）
> IS +409,131（3.890% → **4.028%**・DD 42.55% → **38.87%**）
>
> **0.0060 を採れば IS は 4.065% になるが、それはグリッドの最良点を選ぶ形である。**

## 4. 事前の予想は2つとも外れた

| 予想（`ml/fxqualfloor/measure.py` に測る前に記載） | 実測 |
|---|---|
| 「OOS は 0.0070 以降もほぼ +150,000 で動かない」 | **半分当たり。** 平均は +150,000 前後だが **0.0080 で +108,616 まで落ちた**。取引数が 19 まで減っているのでノイズである |
| 「IS は 0.0080〜0.0100 で頂上を打つ」 | **外れ。頂上は 0.0042〜0.0060**で、`ml/fxqual10` の掃引範囲に**既に入っていた**。0.0080 では既に下り坂（+221,558） |

**端が最良に見えたのは、0.0060 が尖りだったからである。**
