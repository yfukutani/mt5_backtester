# OANDA FX の複利化 — 月利5%には届かない。ただし現行は極端に保守的（2026-09-09）

**結論1:** 目標の**月利5%には到達しない**。48run・24構成すべてで、
OOS窓の最良が **2.71%/月（最大DD 57%）**。両窓とも到達し破綻もない案はゼロ。

**結論2:** ただし**現行設定 `RefCap=78,000` は極端に保守的**だった。
口座50万に対して基準資金78,000円は約1/6で、risk%枠が本来の規模で動いていない。
`RefCap=250,000` / 倍率3 にすると **OOS 0.39% → 1.73%/月（+1.34ポイント）**、
最大DD 27%、**元本割れなし**。

**結論3:** 5%に届かない構造的な理由は、**複利が効くのが9枠中3枠だけ**だから。
残り6枠は固定ロット0.01で口座が育っても増えない。

---

## 1. 何を測ったか

目標が「月利5%の達成」に変わった。非複利では OOS窓で x15.2 相当・拘束DD 86% が必要で
到達不能（`oanda_fx_lot_headroom_20260908.md`）。**複利が唯一の未検証の軸**だった。

`RefCap_PB_USDJPY` / `RefCap_PB_GBPJPY` / `RefCap_CARRY` は risk%枠のロットを決める
基準資金で、**0 にすると口座equity連動＝複利**になる。本番は 78,000 の固定。

24案（`RefCap` 4水準 × `GlobalLotMult` 3水準 × 重み2種）× FULL/OOS の **48run 全成功**。

## 2. 評価指標を複利前提に作り直した

非複利用の指標をそのまま使うと誤る。

| 指標 | 非複利（従来） | **複利（本ラウンド）** |
|---|---|---|
| 月利 | 純益 ÷ 入金 ÷ 月数（算術平均） | **幾何平均**（115か月で16倍と毎月定額は別物） |
| 最大DD | 入金比の円建て | **直近ピーク比**（資産10倍後の30%下落を入金比で見ると300%になる） |
| MT5の相対DD% | 使わない（残高増でリスク過小評価） | **むしろこちらが正しい** |
| 最優先の合否 | DD予算 | **口座破綻の有無** |

破綻したrunを「純益が小さい案」として順位づけると致命的なので、
取引数の激減と最低資産（入金の20%未満）の2つで検出し、破綻案は候補から除外した。

**指標の限界:** equity曲線は決済損益のみで作るため建玉中の含み損を含まない。
**実際の最大DDはここで出た値より深い。**

| | FULL窓 | OOS窓 |

**現行から +1.34ポイント/月（OOS基準）。** 元本を一度も割らない構成としては最良。

より攻める場合は C021（RefCap=500,000・倍率2）で OOS 1.90% / 最大DD 34.2%。
ただし最低資産が 445,202円 まで落ちる（元本割れあり）。

### 重み0.5-0.5 は複利では不利になった

非複利ラウンドでは `Mult_SCA_GBPJPY=0.5` / `Mult_CARRY=0.5` が有利だったが、
複利では**全重み1.0のほうが良い**（C011 4.93% vs C012 4.23%）。

Carry は risk%枠なので複利の恩恵を受ける側であり、その重みを半分にすると
複利の効きも半分になる。**非複利で得た結論を複利にそのまま持ち込んではいけない。**

## 5. なぜ5%に届かないか

1. **複利が効くのは9枠中3枠だけ**。PB USDJPY / PB GBPJPY / Carry のみで、
   FULL窓の純益の32%。残り6枠（RSI×3・Pair・SCA×2）は固定ロット 0.01 で、
   口座が126倍に育っても発注量は変わらない。
2. **OOS窓が上限を決める。** FULL 4.93% に対し OOS 2.71%。
3. **DDが先に限界に来る。** OOS 2.71% の設定は最大DD 57%（しかも下限値）。

## 6. 残された唯一の道筋 — 固定ロット6枠のrisk%化

RSI 3枠・Pair・SCA 2枠は**全体の68%を稼いでいる**。これらが口座規模に連動すれば
複利の効きが3倍になる。EA改修が必要だが、既存の `LotRisk()` を使うだけで実装できる。

**これが未着手の領域として残っている最後のもの。**
