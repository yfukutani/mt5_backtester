## 5. 確立した主要結論

- **月利フロンティア:** 必要DD% = 0.72 ÷（年間リターン/DD比）。現状ブックでは月利6%はレバ非依存で**最大DD55-68%**を伴う。現実的射程は**月利2-3%（年率30-45%）**。
- **増レバはリターン/DDを上げない:** net と DD を同率で動かすだけ。綺麗にスケールするのは PB USDJPY のみ。
- **GOLDは PB GOLD が最適:** 別戦略7案すべて棄却。深い調整＋高コントラクトに短期・タイトストップ順張りが正解。
- **新規無相関源の探索は収穫逓減:** 規律下（OOS/IS両プラス必須）で生存した新枠は VBO/ETH/GBPUSD-RSI の3つのみ。
- **守りでは効率は上がらない:** entry予測ゲートもDDスロットルもリターン/DDを改善せず。DDを下げたいならロット縮小が最効率。
- **効率を上げる唯一の道は無相関源の追加:** それも実証済みテンプレの似た市場への横展開のみ確度が高い。
- **運用ルール:** 新戦略は **OOS/IS 両期間プラスを必須ゲート**とする。
- **ブック確定（2026.06.29）:** 11枠・リターン/DD 12.25（過去最高）を最終構成とし、新規探索を区切る。
