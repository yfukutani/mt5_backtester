## 2. 倍率1は影響を受けていない

**V000 は 1:100 の U000 と純益・DD・取引数まで完全一致**（1,213,378 / 29.5436 / 1,375）。
倍率1では証拠金に届かないので、レバレッジが4倍違っても何も変わらない。

**本番現行（0.39%/月）や T043（2.26%/月）といった低倍率の過去結果は 1:100 のままでも有効。**
無効なのは証拠金に届く構成——倍率2以上・risk%サイジング・枠別の重みを使ったものに限られる。

## 3. 1:25 では、超過した注文は「削られる」のではなく「消える」

cap が無いと、必要証拠金に足りない注文は**まるごと拒否される**。

| 枠 | V001（T036・cap無し） | V002（T036・cap80%） |
|---|---:|---:|
| PB GBPJPY | 1,020,890円 / **9件** | 3,764,913円 / **15件** |
| RSI EURUSD | 750,001円 / 192件 | 323,606円 / **261件** |
| RSI GBPUSD | 795,674円 / 48件 | 1,344,359円 / **60件** |
| 合計 | 2,982,564円 / 1,270件 | 9,474,415円 / 1,329件 |

**cap 無しでは PB GBPJPY の15件中6件が失われていた。**
cap はそれを「小さいロットで建てる」に変える。**失わずに済んだぶんが複利で効く。**

より極端な例が V004（U011の重み・cap無し）で、
**RSI EURUSD（269件）と RSI GBPUSD（62件）が1件も約定しない。**
1取引あたり equity の12%を張るので、必要証拠金が毎回足りない。
欠落354件の内訳は RSI EU 269 + RSI GU 62 + その他23 でちょうど一致する。

## 4. 「A7 は増レバの言い換え」は誤りだった

1:100 では、IS最適重み（U010）と保守版（U011）の純益差は **2.4%** しかなかった。
利益を出す枠のロットがどちらも銘柄上限50に張り付いており、重みが結果に届いていなかった。
そこから「枠別の重みは増レバの言い換えでは」と見立てたが、**1:25 では逆になる。**

| 案 | 構成 | 月利 | 上位3除外 | RSI USDJPY の約定 |
|---|---|---:|---:|---:|
| V004 | U011の重み（RSI_UJ **2**）・cap無し | 4.27% | 1.44% | **80 / 87件** |
| V006 | RSI 3枠一律4倍（RSI_UJ **4**）・cap無し | 1.56% | **−0.85%** | **2 / 87件** |

**`RSI_USDJPY` の重みを 2 → 4 にしただけで、87件中2件しか約定しなくなる。**
V006 は最低資産 340,465円で**元本を割る**。

> [!important] **1:25 の cap 無しでは、重みは「その枠を生かすか殺すか」のスイッチである。**
> 証拠金予算の奪い合いは **1:25 で初めて発生する**。
> 1:100 では予算が余っていたので、重みを変えても何も起きなかった。

## 5. 機構のまとめ

1. **1:25 では証拠金が拘束条件**（1:100 では拘束していなかった）
2. **cap 無し**だと予算超過は取引の全損失 → 重みに極端に敏感（V006 が元本割れする理由）
3. **cap 有り**だと予算内に縮めて全部建つ → 重みは「乏しい証拠金を枠にどう配るか」を決める
4. **A10 と枠別の重みはセットで効く。** cap が予算を使えるようにし、重みが配分を決める

**第4報の「A10 はレバーとしても制約としても死んだ」は撤回する。**
