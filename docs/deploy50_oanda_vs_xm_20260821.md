# 総資金50万円: OANDA構成 vs XM構成の比較（2026-08-21）

## 1. 検証の動機

XMは海外FX業者のため、長期運用に法規制上の懸念がある。GOLDをXMからOANDA CFDへ
移した場合の性能を実測し、OANDA 2口座（FX + CFD）に絞った構成と比較する。

## 2. 前提と制約

- 採用改善: PB GOLD RR 1.8 / SCA GOLD RR 1.7 / PB時間帯ゲート / PB GOLD保有上限64バー
- 入金50万・DD30%制約（相対DD）・倍率は整数のみ
- 期間: IS 2021.06.21〜2026.06.20（60か月） / 全期間 2016.11.09〜2026.06.20（115か月）

### 2.1 OANDAには暗号枠が無い

`MIX_EA_OANDA`には暗号枠（ETH / BTC funding / BfxRev）が実装されていない。
OANDA構成に移すと**暗号3枠の収益が丸ごと失われる**。

### 2.2 事前検査（前回のETH欠落と同種の罠を潰した）

| 検査 | 結果 |
|---|---|
| XAUUSDの長期バックテスト | 成立（全期間630取引） |
| XAUJPY履歴問題 | OANDA端末では発生せず（円建て・USD建てとも同結果） |
| GOLD 2枠の生存 | PB単独108 + SCA単独522 = 両方630 で完全一致 |

**ただし検査能力に差がある。** `MIX_EA_OANDA`のdealログはmagic列を持たず
（`time,profit`のみ）、共通フォルダにも出力されない。XMで使っていたmagic出現
ゲートが使えないため、**枠が無音で脱落した場合の検知能力はXMより弱い**。

## 4. 比較

### 4.1 GOLD単体（OANDA CFD） vs GOLD＋暗号（XM）

**暗号3枠を失う代償は一貫して約27%。** 全期間PFも 1.8983 対 2.0246 でXMが上。

### 4.2 50万円をどう置くか

DD30%以内で成立する主な構成:

| 案 | 構成 | 全期間 月利 | IS 月利 | 最大DD% |
|---|---|---:|---:|---:|
| **X1** | XM単独 x15 | **15.72%** | 24.70% | 25.12 |
| **O1** | OANDA CFD単独 x15 | **11.51%** | 19.92% | 24.53 |
| O2 | OANDA CFD 35万 x10 + FX 15万 x1 | 約 5.6% | 約 9.7% | CFD 17.1 / FX 7.9 |
| O3 | OANDA FX単独 x3 | 2.75% | 3.75% | 20.76 |

配分の計算は、各口座のDD%が入金額に対して非線形なため、単純合成ではなく
実測値からの概算である（O2は参考値）。

**OANDA 2口座に分散すると月利は大きく落ちる。** OANDA FXはPF 1.40と低く、
x3でDD 20.76%を使って月利2.75%しか生まない。資本効率がCFDの1/4程度しかないため、
FXに資金を割くほど全体の月利が下がる。

## 5. 結論

1. **純粋な性能では XM単独 x15（全期間月利15.72%）が最良。** 次点はOANDA CFD単独
   x15（11.51%）で、差は暗号3枠ぶんの約27%。
2. **OANDA CFD単独でも目標月利5%は大きく超える。** x8（全期間6.14%・DD13.98%）でも
   目標を満たし、DDに16pt の余裕がある。
3. **OANDA FXを混ぜると月利が落ちる。** 資本効率がCFDの1/4のため、分散の対価は大きい。

法規制上の懸念を重視するなら、**OANDA CFD単独**が現実的な選択肢になる。
月利は最良案の73%に落ちるが、目標5%は倍以上の余裕で満たす。

## 6. 留意点

- すべてバックテスト。**フォワードで同じDDに収まる保証はない。** x15はDD24〜25%で
  上限まで5〜6pt。フォワードがバックテストを5pt上回れば超過する。
- 高倍率ほどRFが上がって見えるのは、利益の伸びに対しDDの伸びが鈍いためであり、
  リスクが減ったわけではない。円建てのDD額は倍率にほぼ比例して増える。
- OANDA CFDは10年630取引・GOLD 2枠のみ。**統計的な裏付けはXM（748取引）より薄く、
  分散も無い。** OANDA FXは2,926取引と厚いが資本効率が低い。
- OANDAでは枠脱落の検知能力がXMより弱い（4.2節）。運用時はwatchdogで補う必要がある。
