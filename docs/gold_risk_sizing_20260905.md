# GOLD への risk% サイジング — 固定ロットに全面的に劣る（2026-09-05）

**結論:** PB GOLD / SCA GOLD に risk% サイジング（1取引のリスクを口座の一定%に正規化）を
入れると、**固定ロットより明確に効率が悪い。** 両窓・両枠・両ブローカー・複利の有無を
問わず一貫している。**採用しない。**

---

## 1. なぜ試したか

GOLDの収益アップで唯一残っていた未探索領域だった。

| 領域 | 案数 | 結果 |
|---|---:|---|
| GOLD別戦略7案（レンジ逆張り/長期保有/金銀比価/ブレイク/リスクオフ/季節性/対ドル） | 7 | 全滅（`rejected_strategies.md` §1） |
| 利益保護（BE/トレール/giveback/部分利確） | 500 | 採用ゼロ（`profit_protection_20260902.md`） |
| SCA GOLD 利確側（RR/TP/強制決済/締切） | 290 | 採用ゼロ（`sca_gold_exit_20260904.md`） |
| GOLD DD低減（エントリー品質/重複制御/クールダウン） | 1,380 | 保有上限64バーのみ採用 |
| **PB/SCA GOLD の risk% サイジング** | — | **未検証** |

`docs/position_sizing.md`（2026-06-27）のサイジング検証は PullbackTrend USDJPY /
RSI_Reversal / PairTrade で実施され、**PullbackTrend が最良の反応**を示していた
（利益3.6倍・PF 1.21→1.35・net/DD 単調改善）。**PB GOLD は同じ PullbackTrend 型なのに
固定0.01のまま**残っていた。理由は「0.01が最小ロットで下げられない」だったが、
入金50万・倍率x4なら実効0.04となり調整余地が生まれる。

A-1（GOLDの1取引リスクが設計の5.7倍）への直接の対処でもあり、フォワード損失 −13.11% の
主因に効く可能性があった。

## 2. 実装と、潰した罠

`MIX_EA_OANDA_SIMVERIFY.mq5` と `MIX_EA_SIMVERIFY.mq5` に GSZラボ（7入力・既定OFF）を追加。

**【通貨の罠】** 既存の `LotRisk()` は `SYMBOL_TRADE_TICK_VALUE` を使うが、この値は
GOLD/暗号のようなUSD建て銘柄では**口座通貨に換算されずUSDのまま返る**
（`profit_trail_20260805.md` §2 の実害記録）。そのまま有効化すると
**ロットが USDJPY 倍（約150倍）過大**になる。本ラボは `OrderCalcProfit()` を使い、
建値通貨・契約サイズ・クロスレートを端末側に解決させる。本番経路は変更していない。

**検証（すべて通過）**

| 検査 | 結果 |
|---|---|
| 回帰 | `GszMode=0` で全602 deal の時刻・価格・数量・SL が完全一致（差は profit のみ＝スワップ） |
| 検算（下） | risk 0.68% → 全59件が0.01ロット。理論値0.0100と整合 |
| 検算（上） | risk 5.00% → 平均0.0666ロット・0.01〜0.14に分散。150倍ずれなし |
| 端末非依存 | BT3 と BT4 で純益が完全一致（1,025,408） |
| ブローカー間 | OANDA 2.49倍/DD3.7倍、XM 2.27倍/DD4.25倍と同型 |

**あわせて条件ずれを1件解消した。** 検証用XM版 `MIX_EA_SIMVERIFY.mq5` には
採用済みの `GoldPBHoldBars`（PB GOLD 保有上限64バー）が移植されておらず、本番XM版
`MIX_EA.mq5` にのみ存在していた。本ラウンドで本番と同一実装を追加した。

## 4. 固定ロットとの比較 — 2〜3倍の差

固定ロットはロットが一定なので**純益倍率は倍率そのもの**（x5なら5.00倍）。
DD倍率は `ml/deploy50b/results_xm.csv` の実測から求める。

| 方式 | 純益倍率 | DD倍率 | **効率** |
|---|---:|---:|---:|
| **固定ロット x3** | 3.00 | 2.18 | **1.38** |
| **固定ロット x5** | 5.00 | 2.85 | **1.75** |
| **固定ロット x8** | 8.00 | 3.45 | **2.32** |
| **固定ロット x15** | 15.00 | 4.60 | **3.26** |
| risk% 最良（PBcomp_r3.0・IS） | 2.19 | 2.48 | 0.89 |
| risk% 最良（PB_r0.68・OOS） | 1.17 | 1.46 | 0.80 |

> ※ deploy50b のXM測定は `GoldPBHoldBars` 追加前のEAで、基準DDが 5.23%（本ラウンドは4.06%）
> と異なる。ただし効率の差（固定 1.4〜3.3 対 risk% 0.35〜1.09）はその不一致より桁が大きく、
> 結論は動かない。

**固定ロットは倍率を上げるほど効率が改善する**（1.38 → 3.26）のに対し、
**risk% は水準を上げても 0.4〜0.9 のまま**である。

## 5. なぜ効かないのか

risk% サイジングは「SL幅が狭いときロットを大きく」する。GOLDではこれが裏目に出る。

1. **SL幅の狭い場面が、比例して有利ではない。** 平均ロットが6.66倍になっても純益は
   2.27倍にしかならない（IS・PB_r5.0）。大きく張った取引が相応に払っていない。
2. **ロットのばらつき自体がDDを増やす。** 固定ロットならDDは倍率に対して緩やかにしか
   増えない（x15で4.60倍）が、risk% では純益倍率とほぼ同率かそれ以上にDDが増える。
3. **SCA GOLD で最も悪い。** PFが IS 2.08→1.53、OOS 1.58→1.34 と大きく劣化する。
   レンジ幅がそのままSL幅になる枠なので、狭いレンジ＝大ロットとなり、
   ブレイクの信頼度が低い場面に最も大きく張ってしまう。
4. **複利（equity追従）も救わない。** `position_sizing.md` で PullbackTrend USDJPY の
   利益3.6倍を生んだ主因だったが、GOLDでは IS 0.89 / OOS 0.59 にとどまる。

`position_sizing.md` の結論「サイジングは EA の質で効き方が真逆」は GOLD にも当てはまり、
**PB GOLD は PullbackTrend 型でありながら USDJPY 版とは逆側に落ちる**、というのが本ラウンドの
追加知見である。

## 6. 推奨

1. **risk% サイジングは採用しない。** GOLD のサイズ調整は**固定ロット×倍率**で行う
   （`deploy50_recheck_20260905.md` の推奨 x4 はそのまま有効）。
2. **A-1（GOLDの過大リスク）はサイジングでは解けない。** 1取引のリスクを均そうとすると
   全体の効率が落ちる。リスクを下げたいなら倍率を下げるのが最も効率的である。
3. ラボは既定OFFで温存する。他銘柄・他枠へ適用する際の土台になる。

## 7. 測定上の注意（次ラウンドへの申し送り）

- **XM で JPY建て・GOLD を測るときチャート銘柄を GOLD にしてはいけない。** MT5 が通貨換算に
  `XAUJPY` を要求し、XMの XAUJPY 履歴が 2025.09.17 以降しかないため
  OOS 期間が `no history data` で落ちる（GOLD 自体は 2008.02.19 から揃っている）。
  **チャート銘柄は USDJPY にする。**
- **MT5 の LiveUpdate が測定を止める。** 2026-09-05 に OANDA 5端末すべてが
  build 6140→6180 の自動更新に捕まり、起動のたびに
  `LiveUpdate failed to create copy ... [32]` → `Terminal exit with code 0` で
  テストを実行せず約24秒で終了するようになった（フォワードレポートの S-12 と同型）。
  更新ファイルのフォルダはMT5に保護されており、全プロセス停止後も `Access denied` で
  退避できない。**XM端末は先に 6180 へ更新済みで影響を受けなかった。**
  同型の事象では、更新済みの端末に退避するか、更新を完了させるしかない。
