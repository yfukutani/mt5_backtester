## 2. ⚠️ deal ログの「切り直し」は予測に使えない — 3回破れた

しきい値の候補を絞るのに、deal ログから「下限を入れたら合計はいくらになるか」を
切り直した（`dist/entry` は EA 1925-1928行の判定式そのもの）。
**この手続きは screening にしか使えない。** 理由が3つある。

### (1) `ScaFilRangeMin` は**日内で解除されるゲート**である（並行セッションの指摘）

```cpp
if(ScaFilRangeMin>0.0){
   if(entry<=0.0) return false;
   if(dist/entry < ScaFilRangeMin) return false;   // EA 1925-1928
}
```

`dist` は SL距離（買いなら `ask − scaRangeLow`）、**`entry` はその時点の `ask`** である。
`scaRangeLow` は日内固定でも **`ask` は動く**ので、価格が上がれば `dist/entry` は増える。
**09:15 の初回ブレイクが閾値を下回って止められても、10:00 の再ブレイクでは通る。**
`scaTradedL` は発注成功時にしか立たないので、その日の枠は終わっていない。

**第5ラウンドの時間帯ゲート（[round5](oanda_fx_sleeve_quality_round5_20260919.md)）と同じ機構の、弱い版**である。
実測されたずれ率（`ml/fxqual9/shift.py`・F006）は **OOS 7% / IS 18%**。
時間帯ゲートの 89% よりずっと小さいが、ゼロではない。

### (2) 複利では、止めた取引が後続のロットを変える

負けを1件止める → その時点の equity が上がる → **以降の全取引のロットが増える。**
切り直しは元のロットのまま足しているので、この経路を含まない。

**`F002 → F003` では、触っていない枠の変化が全体の 66% を占めた:**

| 枠 | F002 | F003 | Δ | EA を触ったか |
|---|---:|---:|---:|---|
| PB USDJPY | 23,029 | 99,898 | +76,869 | **触った**（slope 1.40） |
| RSI USDJPY | 24,142 | 51,619 | +27,477 | **触った**（mech 124） |
| PB GBPJPY | 299,856 | 360,346 | **+60,490** | 触っていない |
| Carry | 283,163 | 327,212 | **+44,049** | 触っていない |
| SCA GBPJPY | 307,007 | 396,463 | **+89,456** | 触っていない |
| RSI GBPUSD | 94,106 | 102,891 | +8,785 | 触っていない |
| RSI EURUSD | 15,863 | 11,174 | −4,689 | 触っていない |
| SCA USDJPY | −59,795 | −70,521 | −10,726 | 触っていない |
| Pair | 1,996 | 2,008 | +12 | 触っていない |
| **合計** | **989,367** | **1,281,090** | **+291,723** | |

**触っていない7枠の和は +193,995 ＝ 全体の 66%。**

> [!danger] **「枠別の効果は1円まで足し算」は固定ロットでしか成立しない。**
> 第4〜8ラウンドで7例確認した加算性は、**すべて本番現行サイジング（固定ロット相当）**での話である。
> **複利のラウンドで枠別Δを引き算してはいけない。**

### (3) 実測で、切り直しは片側で符号を外した

同じ手続きを**固定ロットの `F000` ログ**に当て、`F006`（`ScaFilRangeMin=0.00595`）と突き合わせた:

| | 切り直し | **実測（F006）** | 判定 |
|---|---|---:|---|
| OOS | +4,975（0.0056）〜 +3,678（0.0060） | **+3,991** | **当たり**（帯の内側） |
| IS | −1,060（0.0056）〜 **−6,425**（0.0060） | **+3,393** | **符号ごと外れ** |

IS の外れ幅（+7,400〜+9,800）は、**ずれ率 OOS 7% / IS 18% と向きも大きさも整合する**——
止められた負けが生き返るのではなく、**止められた勝ちが後ろへずれて戻ってきている。**
**OOS（ずれ 7%）で当たり、IS（ずれ 18%）で外れる、という並びも合う。**

> [!note] **手続きの算術は壊れていない。壊れているのは前提である。**
> 同じスクリプトは [last_axes](oanda_fx_last_axes_20260915.md) の B1 上位50%
> （残の純益 **+2,751** / Δ **+4,975**）を **1円まで再現する。**
> 誤っているのは **「止めた取引は消える」** という前提のほうである。

## 4. 事前の予想（**測る前に書く**）

> [!warning] **切り直しの数字は予測に使わない。**（§2 で3回破れている）
> 信じるのは**符号の向きだけ**である——「SL距離の最小分位が両窓とも単独で最悪」は
> 分位に頼らない粗い事実で、09-15 の独立な四分位分割とも一致する。

> [!warning] **⚠️ 訂正 — 当初ここに「`G006` が掃引の上限値になる（どの点も超えない）」と書いた。逆である。**
> `G006` は SCA USDJPY の **266取引を全部消す**ので、この枠の寄与が **0** になる。
> 下限フィルタは**そのうち赤字のものだけを消して黒字のものを残す**のだから、
> **残りが黒字なら、下限フィルタは `G006` を上回るはずである。**
> 切り直しでも `thr=0.0042` で残る取引の合計は **+38,213**（0 ではない）。
>
> **正しい役どころは「上限値」ではなく「この枠が無いのと同じ」の基準線**である:
>
> | 結果 | 意味 |
> |---|---|
> | **どれかの掃引点が `G006` を明確に上回る** | 下限フィルタには価値がある。**残した取引が枠の存在を正当化している** |
> | **どの掃引点も `G006` を超えない** | **SCA USDJPY を複利構成から外すのが正解**。フィルタを調整する話ではなくなる |
>
> **後者なら、それはそれで決着である**（第10ラウンドで「枠を1つ畳む」という結論が出る）。
> 当初の書き方は、`G006` を「達成不能な理想」と取り違えていた。

| 項目 | 予想 |
|---|---|
| **どれかの掃引点が `G006` を上回る** | **上回ると予想する**（切り直しでは残る取引が +38,213）。ただし**自信は低い**——切り直しは IS で符号を外している |
| OOS 幾何月利 | 2.337% → **2.4〜2.8%**（自信は低い。±0.2pt で当てられるとは思っていない） |
| OOS 最大DD | 28.47% → **25〜29%**（赤字枠の増幅を消す施策なので下がるはず。**上がったら機構の理解が間違い**） |
| 目標への寄与 | **+0.1〜0.4pt。この軸だけでは 6% に届かない。** 不足 2.66pt に対し**桁がひとつ足りない。** |

### 比較のしかた（並行セッションの指摘）

**`G006` と掃引点を比べるときは、2つを分けて見る:**

| 問い | 見る数字 |
|---|---|
| **採否**（どれが一番いいか） | **ブックの幾何月利と最大DD。** 本番で受け取るのはこれだから |
| **機構の確認**（フィルタは何をしたのか） | **SCA USDJPY の枠純益。** ブックで見ると、`G006` が equity 経路を大きく変えて **触っていない枠の損益まで動かす**ぶんが「フィルタの効果」に混ざる |

§2(2) のとおり、**複利では枠別Δの引き算が成立しない。**
枠純益も equity 経路の影響を受けるので、**完全に分離はできない。**
それでもブック純益よりは機構に近い。

### 採否の基準（**先に書く**）

1. **両窓プラスが 3点以上連続していること。** 1点だけ突出しても採らない
   （第16報 `V007`・第7ラウンド `Z007` で同じ失敗を2回している）。
2. **採るなら帯の中央。ピークを採らない。**
3. **最優先の合否は口座破綻の有無。** 次に最大DD が悪化していないこと。

### 過学習について正直に書く

**しきい値は OOS と IS の deal ログを見て決めた。**
したがって **このラウンドの OOS は、この軸については out-of-sample ではない。**
そのうえで単なる曲線あてはめでないと考える理由は2つある:

1. **機構が先にある。** 「狭いレンジ → risk%で大ロット → ブレイクは騙し」は
   2026-09-15 に**この解析より前に**文書化されている。
2. **09-15 の独立な分割と一致する。** 同 doc は FULL窓・固定ロット・594取引で
   SL距離の四分位を割り、「**利益はレンジが広い半分だけが作っている。狭い半分は赤字**」
   と結論している（最小25% の中央値 0.321・25-50% の中央値 0.455）。
   **比に直すと 0.0029〜0.0041** で、本ラウンドの帯とほぼ同じである。
   **私が見る前に、別の窓・別のサイジングで同じ境界が出ていた。**

**それでも FULL窓で確認するまでは採用しない**（採用候補が絞れてから別ラウンドで測る）。

**この但し書きは本ラウンドにも当たる。** レンジ幅下限は「取引除外」に見えるが、
**除外するのが risk% サイジングで過大に重みづけされた取引**である点が違う。
**1取引あたりの期待Rを上げる方向に働く**——ただしそれは仮説であって、実測で決める。

| こちらが出した方向 | Codex の回答 |
