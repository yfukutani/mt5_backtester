## ご質問への回答

### PB の slope を締める価値

あります。ただし「PB USDJPY は頻度ではなく質が問題」という読みは、半分だけ正しいです。

LOOでは slope が唯一の律速で、緩和により低品質な取引が増えて悪化しました。したがって、締めれば残る集合の平均品質が上がる、という機構仮説は筋が通ります。一方、UJ の OOS 18件・GJ の15件では、数件の損益だけで結果が反転します。よって上記4点は測る価値があっても、良い結果を「発見」するためではなく、この仮説を閉じるためです。PBの正の結果は、少なくとも合計30〜60件級の再検証がない限り採用しないのが安全です。

### 条件0（up）・条件3（陽線）は冗長か

「このデータで、他の7条件が満たされる直前まで来た候補を、単独では一度も落としていない」という意味では正しいです。ただし、論理的に常に同値とは限りません。

特に `up` は最終ANDだけでなく、`armedBuy/armedSell` の解除・設定にも使われます。最終ANDから外すだけでは armed 条件が残るため、実取引は増えません。陽線も、現データでは他条件を満たしてなお陽線だけが欠ける場面がゼロでした。外しても約定集合は変わらない見込みなので、試験価値はありません。

### SCA USDJPY と GBPJPY の差

時刻とORB骨格は同じでも、実装上は同一ではありません。

- USDJPY：`scaBuf=0.10`、RevBoost `2.0`
- GBPJPY：`scaBuf=0.0`、RevBoost `6.0`

また、発注数自体も OOS で266対621と大きく違います。GBPJPYの利益差は、単に「より良い銘柄」ではなく、GBPJPYのロンドン開始後の値幅・ブレイク頻度と、逆行ドリフト時に6倍へ増える設計が組み合わさった結果です。Boost は損益額を拡大できますが、取引数差までは説明しません。

USDJPYの OOS −2,224円は266件に対して1件あたり約−8円であり、「質が壊れている」と断定するほどの負けではありません。9時以外に明確な選別根拠もありません。したがって、USDJPYをGBPJPY仕様へ寄せる再最適化は、現段階では選別バイアスの強い軸です。GBPJPYの9時除外だけを確認し、UJは計装で原因を読む、が妥当です。

このテーマで現実的に採れるのは、SCA GBPJPY の時間帯フィルタが通った場合の **+0.03〜0.05pt/月**、RSI USDJPYのV001を含めても **合計+0.04〜0.06pt/月程度**です。
