# OANDA FX：証拠金律速から月利6%を目指す50案

作成日：2026-09-15。**提案のみ。EAの実装、コンパイル、バックテストは行っていない。`backtest.ini` は読んでいない。**

## 前提と読み方

- 最新の基準は依頼文の実測値を採用する。X005は `FxRiskMask=7 / FxRiskPct=1.0 / FxRiskRefCap=0 / GlobalLotMult=3 / MarginCapPct=80`、枠別重みも依頼文どおり。OOS窓月利中央値4.82%、通期OOS月利8.58%、最大DD62.0%。古い資料の「到達不能」という結論や1:100の成績へ戻らない。
- 比較対照はX005のcap80と、そのcap90版（月利中央値5.12%）。**cap90から必要なのは月利+0.88ポイント**。6/5.12≒1.172は月利の比であり、利益額を一律17.2%増やせば達成するという意味ではない。24か月なら終端資産比は `(1.06/1.0512)^24 ≒ 1.22` になる。
- 証拠金律速を前提とする。ただし、空いた証拠金に**その時点で正の期待値の注文があること**が改善の必要条件。純益/証拠金日のIS平均順位は候補選別に使えても、増額時の限界収益やOOS順位を保証しない。
- Carry / PB UJ / RSI EU停止と `GlobalLotMult=4〜6` の16案は結果待ちとして扱い、50案に数えない。その勝者が確定したら追加の比較対照にする。以下の「存続させて作り直す案」は、停止案を上回れなければ不採用。
- **◎＝診断とコードに直接対応し優先検証、○＝筋の通った仮説、△＝見込み低い、×＝現条件で極めて低い。達成確率や実証済みエッジの表示ではない。** 未測定なので月利上昇幅は捏造しない。単独で+0.88ポイントを狙う有力仮説と、小幅な補助策を区別する。
- 銘柄追加、反対注文の相殺、通貨集中上限、固定RefCap、SCA買い限定・レンジ幅フィルタ・採用済み09時除外の再提案はしない。棄却記録にあるSCA第2セッション、一般的な偽ブレイク逆張り、三角裁定、PB低ボラ停止、DD連動一律減量も除いた。
- 新戦略も既存FX銘柄に限定し、低効率枠を置き換えて最大9枠に収める。GOLD・暗号・海外高レバ口座は対象外。

## 共通の検証規約

**ログ一次**＝既存dealログで保有時間・量・実現損益等を使う候補選別。**価格追加**＝当時のBid/Ask・バー・換算レート等が必要。**MT5必須**＝最終的な月利効果にはブック全体の再実行が必要。今回その作業は実行しない。

1. 全案をレバレッジ1:25、JPY、新規500,000円、同じ費用条件・`every_tick` で比較する。W1=2016-11〜2018-11、W2=2017-11〜2019-11、W3=2018-11〜2020-11を各々リセット。日付・月数は元の実測と一致させ、便宜上すべて厳密な24か月と決めつけない。
2. 主指標は各窓の幾何月利 `g_w=(終端equity/500000)^(1/月数)-1` の3窓中央値。窓末建玉の扱いを固定する。元集計が残高式なら同式も併記し、equity式との混同を避ける。通期8.58%を窓中央値の目標達成と取り違えない。
3. equity最大DD、最悪窓月利、月次損失、維持率最小値、発注量削減/不成立、費用込み純益、証拠金日も併記。依頼文の62.0%はDD定義が明記されていないため、勝手にequity DDと呼ばない。cap80/90は発注時の制限であり、全時点の安全性の証明ではない。
4. IS=2021-06〜2026-06内部の分割で、各案の少数の粗い設定と停止条件を決めて凍結し、W1〜W3で比較する。既存ルールに対して完全OOSだった3窓も、今回の成績を見て案を選び直すほど開発用になる。3窓は重複しており独立3標本ではない。将来の未使用期間での確認を別に残す。
5. まず単独変更、次に少数の有望案だけ組み合わせる。月利改善の単純足し算はしない。最終採用は中央値6%以上に加えて各窓、DD、維持率の悪化を開示して判断する。50案からの最高値だけでは再現性を主張しない。
6. ログから除外後の既存約定損益を集計できても、浮いた証拠金による新規約定、複利量、途中退出後の再エントリーは再現できない。**本ブックの月利改善を既存dealログだけで確定できる案はない。** 証拠金日の厳密な再計算にも当時の価格・仕様が必要で、入口証拠金×保有日数は近似と明記する。

## 着手順の提案

まず結果待ちの16案を比較対照へ加え、**#4（EU建玉量）→#11（EU期限）→#31（Pair平均到達退出）→#1（退出先行）→#2（発注順位）**を単独で確認するのがよい。理由は、既知の占有源か確認できたコード構造に直結し、反証条件も明確だから。

次に#12/#13でEUの利益を残せるか、#18/#21で停止よりよい存続形があるかを確認する。#36は利益案としての期待より、両脚合計の制約が実際に成立しているかを確認する位置付け。有望案の組合せは最後に少数だけ測る。

**優先案で利益/証拠金日の改善が出なければ、50案あることを到達可能性の証拠にしない。** 新エッジ8案はデータ・費用・標本数の難しさから総じて見込みが低く、月利6%の確約材料にはならない。
