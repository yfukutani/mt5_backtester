# 暗号系厳格改善のOOS再測定（ETH込み）— 2026-08-14

## 1. 背景

`docs/eth_history_investigation_20260813.md` の通り、round6_phase2のOOS構成48件はすべて
開始日 2016.06.21 で走らせていた。ブローカーのETHUSD履歴開始は 2016.11.08 であり、
テスト開始時点でバーが存在しないため ETH枠の `iMA` が error 4805 で失敗し、
戻り値を検査していなかったため**無音で枠ごと脱落**していた。

つまり従来「暗号3枠」と称していたOOS値は、実体は **BTC funding + BfxRev の2枠**だった。
本ドキュメントは、開始日を 2016.11.09 に改めてOOSを測り直した結果である。

## 2. 検出漏れ対策

従来の `run_decomposition.py` は結果ファイルの存在しか見ておらず、枠が消えていても
「成功」として通した。これが最終報告まで欠落が届いた直接の原因である。

再測定では `assert_magics_present()` を追加し、**生成されたdealに各枠のmagicが実際に
現れること**を検査する。dealログは EA側が `FileOpen(..., FILE_COMMON)` で書くため、
`results/<run>/` ではなく共通Filesフォルダ
（`%APPDATA%\MetaQuotes\Terminal\Common\Files`）に出力される点に注意。

またdealログのファイル名はランごとに一意にする。従来は全ランで同名だったため
上書きされ、そもそも枠の検査ができない状態だった。

## 4. 判定の訂正

厳格改善の定義は「両期間で純利益・PFが向上し、DDが悪化しないこと」。

**D5（ショック5%）: 厳格改善から脱落。** ETHを含めるとISで純利益 866→756（−12.7%）、
PF 3.1744→2.8725、DD 6.7133→7.2801% と、三指標すべてが悪化する。
ETH欠落時にISで改善に見えていたのは、ETHの取引が抑制対象から外れていたためである。

**D10（ショック10%）: 形式上は厳格改善を維持。** ただし内実は分けて読む必要がある。

- OOSは実質的な改善: 純利益 +296→+418（+41%）、PF 1.6562→2.0020、DD 12.7197→11.9927%
- ISはほぼ無差: 純利益 +866→+867（+0.1%）、DD改善 0.0023pt

つまりD10は「ISで利益を増やす案」ではなく「**ISを損なわずOOSの頑健性を上げる案**」である。
IS利益優先の方針（[[mt5-tradeoff-preference]]）に照らすと、ISで得るものはないが失うものも
ない、という位置づけになる。

## 5. 「最大整数倍率1倍」の結論について

この再測定は暗号3枠単体の話であり、XM合算の倍率結論をそのまま更新するものではない。
XMのDDはGOLDが支配しており（GOLD2枠だけで32.05% / XM5枠合計33.64%）、
倍率は暗号側だけでは決まらない。

一方で、**round6_phase2のOOS 48構成はすべてETH欠落状態で測られている**ため、
それらのOOS値を根拠にした判断は再測定なしには使えない。XM5枠合算での倍率再導出は
別途フルブックで測り直す必要がある。現時点で倍率結論を変更しない。
