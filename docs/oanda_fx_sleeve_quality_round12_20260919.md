## 0. このラウンドが閉じるもの

Codex の棚卸し（[inventory](codex_oafx_inventory_20260919.md)）が「未実装・未測定」として
残した軸は3つ。**本ラウンドでそのうち SCA の2つを実装して測る。**
残る1つ（RSI 3枠の機構別退出）は改修が大きいので次ラウンドに回す。

[Codex の第12ラウンド査読](codex_oafx_round12_20260919.md)も
**「測る価値が残るのはその3軸だけ。PB 2枠・Pair・Carry には追加案は無い」**で一致した。

そこに、**deal ログの読み直し**（[SCA の退出の解剖](oanda_fx_sca_exit_anatomy_20260919.md)）で
新しく見つけた軸を1つ足す。

## 1. EA への追加（既定 0 で完全に inert）

| input | 内容 |
|---|---|
| `ScaRR_UJ` / `ScaRR_GJ` | >0 で SCA 親枠の TP を `rr×SL距離` に上書き。0 なら枠の既定 2.0 |
| `ScaOvsATR_UJ` / `ScaOvsATR_GJ` | >0 で「ブレイク終値のレンジ端からの超過幅 ÷ ATR」の上限。0 で無効 |

実装は `ScaRROver()` と `ScaOvsOK()` の2関数だけで、**`ProcSCA` の TP 計算と
ブレイク判定に1箇所ずつ足した**。`S[i].rr` を返すだけなので **GOLD や第2セッションの
SCA 枠には一切触れない**（magic で分岐）。

⚠️ **overshoot の超過幅は buffer を含む。** USDJPY は `buffer=0.10×ATR` なので、
上限を 0.10 以下にすると1本も通らない。**`OnInit` で 0.10 以下を弾く**ようにした。
GBPJPY は `buffer=0` なので下限の制約が無い。

## 3. 事前の予想（外れたら記録する）

| 案 | 予想 | 根拠 |
|---|---|---|
| Q005 / Q007（rr を**上げる**） | **ほぼ 0** | 実現 R倍率の最大は TP の 2.000R ちょうど。**2R を超えて走った取引は4ケースで1件も無い。** TP 発火は 1.0〜7.1% しかないので、93〜99% は no-op |
| Q006 / Q008（rr を**下げる**） | **両窓マイナス** | 実現 R を k で頭打ちにした下界が4ケースすべてマイナス（OOS GJ 426,099 → −304,632 @1R）。第17報の建値ストップと同じ機構 |
| Q009〜Q012（overshoot 上限） | **ほぼ 0** | overshoot が大きい取引は `dist=|entry−SL|` が大きく、risk% では**ロットが小さい**。この上限は**重みの軽い取引**を落とす。`ScaFilRangeMin`（重い取引を落とす）とは**逆向き**で、ブックへの効きは一桁小さいはず |
| Q001（重み 0.5） | **OOS 月利 −0.22pt・DD −3.9pt / IS 月利 +0.11pt・DD 横ばい** | 下記の一次近似 |
| Q002（重み 0.25） | **OOS 月利 −0.34pt・DD −4.96pt / IS 月利 +0.17pt・DD +0.65pt** | 同上 |
| Q003（重み 0.0） | **OOS 月利 −0.46pt・DD −4.64pt / IS 月利 +0.22pt・DD +1.64pt** | 同上。**0 は内点より悪い**はず |
| **Q004（重み 0.25 ＋ 倍率2）** | **五分五分** | DD を揃えたときに月利が上がるかどうか。**ここが本命** |

**Q001〜Q004 の理屈（初稿から差し替え）:**
初稿は「SCA GBPJPY は1取引の期待値がゼロ」と書いたが、**これは誤りだった**
（[SCA の退出の解剖](oanda_fx_sca_exit_anatomy_20260919.md) §4 で訂正済み）。
**equity で割れば sca_gj は両窓プラス**（OOS +52.6% / IS +29.2%）で、第21報と一致する。

**正しい理屈は DD のほうである。** deal ログの `profit` を sca_gj だけ定数倍して
残高曲線を引き直すと（⚠️ risk% では他8枠のロットも変わるので一次近似）:

| 窓 | 倍率 | 幾何月利 | 最大DD | 月利÷DD |
|---|---:|---:|---:|---:|
| OOS | 1.00 | 2.488% | 23.45% | 0.106 |
| **OOS** | **0.25** | **2.151%** | **18.49%** | **0.116** |
| OOS | 0.00 | 2.024% | 18.81% | 0.108 |
| IS | 1.00 | 4.028% | 38.87% | 0.1036 |
| **IS** | **0.25** | **4.195%** | **39.52%** | **0.1062** |
| IS | 0.00 | 4.247% | 40.51% | 0.1049 |

**月利÷DD は両窓とも 0.25 で最大**になり、**0.00 まで落とすと両窓とも悪化する（内点がある）。**
**だから測るのは「重みを下げること」ではなく「下げて空いた DD を倍率で買い戻せるか」である。**

> [!important] **第22報の「複利では枠別損益はブックの分解ではない」があるので、
> 上の一次近似がそのまま出るとは予測しない。** SCA GBPJPY を risk% から外した
> `ml/fxqual10` の `G008`/`G009` では、**枠自身は改善したのにブックは 250,202 悪化**した。
> 全枠が同じ equity を共有するので、**ある枠の利益が他の8枠のロットを大きくしている。**
> **一次近似と実測がどれだけずれるかも、このラウンドで測る量のひとつである。**

## 4. 見込みについて、正直に

**このラウンドで月利6%に届く見込みは無い。**
Codex は3軸すべてを **「0.00pt 中心・定量幅なし」** と査読しており、
こちらの deal ログ解析も **TP 軸と overshoot 軸は事前期待ゼロ**を支持している。
**唯一、上振れの余地があるのは Q004（重み配分の付け替え）だけ**で、それも五分五分である。

**現在地は 全複利・倍率1 で OOS 2.488%。目標まで 2.4倍。**

## 4.5 ⚠️ このラウンドの既知の欠落 — **equity DD を取っていない**

`ml/fxqualexec` は `m3.CAP_LOG = True` を立てていたので **equity DD（含み損込み）**が
記録されたが、**本ラウンドは立て忘れた**。したがって `results.csv` に出るのは**残高DD だけ**である。

**第23報で確認したとおり、OOS では equity DD が残高DD より 11〜16pt 大きい。**
**残高DD だけで採否を論じてはいけない。**

**走行中に `measure.py` を直すと、直す前後の run で渡す config が変わる**ので触らない。
**採用候補が出たら、その構成だけ `CAP_LOG=True` で測り直す**（確認ラウンドを1本足す）。

## 5. 実測（追記）

### 5.0 ✅ 回帰試験は両窓とも合格

`Q000` は **OOS +1,431,459 / IS +4,845,523** で `ml/fxqualexec` の `E000` と**1円まで一致**した
（取引数 1188 / 1452 も一致）。**`ScaRR_*` と `ScaOvsATR_*` は既定 0 で完全に inert。**

> [!important] **OOS で月利が +0.197pt 上がり、残高DD が −12.45pt 下がった。**
> **このテーマで初めて、倍率を上げた構成の損益とDDが同時に改善した。**
> 月利÷DD は **0.0696 → 0.0985（＋41%）。**
> IS は月利 −0.683pt・DD −0.62pt で、**IS は素直に悪い。**

> [!danger] 🔴 **それでも `Q004` は推奨しない。ユーザーの既定方針に反するからである。**
>
> **「IS と OOS のトレードオフが出たら、現状市場（IS＝2021-2026）の利益を優先する」**
> がユーザーの明示した方針である（2026-08-08・PB 2枠の判断で確立）。
> **`Q004` はまさにそのトレードオフで、しかも負ける側が大きい:**
>
> | | OOS | IS |
> |---|---:|---:|
> | 月利の変化 | **+0.197pt** | **−0.683pt** |
> | 月利÷DD | 0.0696 → **0.0985** | 0.1106 → **0.1013** |
>
> **IS の失点は OOS の得点の 3.5倍**で、**IS はリスク調整後でも悪化している。**
> **`Q001`〜`Q003` も IS は3点とも対照より悪く、IS 最適は重み 1.0（＝現行）である。**
>
> **したがって Group C は棄却する。**
> **「重み × 倍率」の面を掃く次ラウンドも、この軸については意味が無い**
> ——IS 側に上り坂が無いことが4点で分かったからである。
>
> ⚠️ **ただし本タスクの指示は「最終目標は月利6%（OOS窓）」**であり、
> **OOS を判定窓とするなら `Q004` が現時点の最良（3.625%）**になる。
> **既定方針（IS 優先）と本タスクの判定窓（OOS）が食い違っている。**
> **これはこちらで決めずユーザーに出す。**

### 5.2 🔴 事前予想は **OOS が当たり・IS が符号ごと外れた**

deal ログの `profit` を sca_gj だけ定数倍した一次近似で、こう書いてあった:

| 案 | **予想（OOS 月利 / DD）** | **実測** | **予想（IS 月利 / DD）** | **実測** |
|---|---|---|---|---|
| Q001 | −0.22pt / −3.9pt | **−0.314pt / −3.97pt** | **+0.11pt** / 横ばい | **−0.327pt** / +0.90pt |
| Q002 | −0.34pt / −4.96pt | **−0.482pt / −4.27pt** | **+0.17pt** / +0.65pt | **−0.205pt** / −0.24pt |
| Q003 | −0.46pt / −4.64pt | **−0.558pt / −4.32pt** | **+0.22pt** / +1.64pt | **−0.136pt** / −0.24pt |

- **OOS は3点とも方向・桁とも当たった**（DD の低下幅は 4pt 前後でほぼ的中）。
- **IS は3点とも符号が逆だった。** 一次近似は「+0.11〜+0.22pt」、実測は「−0.136〜−0.327pt」。

> [!warning] **これは第22報「複利では枠別損益はブックの分解ではない」の3例目の実証である。**
> IS の sca_gj は**円建てで −719,706** なので、
> **「重みを下げれば IS のブックは良くなる」は算術的には正しく見える。**
> **実測では3点とも逆に悪化した。**
> `ml/fxqual10` の `G008`/`G009`（risk% から外すとブックが 250,202 悪化）と**同じ向き**である。
> **全枠が同じ equity を共有するので、負けている枠でもロットを下げると
> 他の8枠に回る資金が減る。** deal ログの掛け算では、この経路が表現できない。
>
> **一次近似が使えるのは OOS 側だけだった。** 使える窓と使えない窓がある。

### 5.3 内点はあった（`Q003` は `Q002` より悪い、ただし OOS だけ）

OOS では **1.0 → 0.5 → 0.25 → 0.0 で月利が単調に下がり、DD も単調に下がる**
（23.45 → 19.48 → 19.18 → 19.12%）。**DD の低下は 0.5 でほぼ終わっている**ので、
**0.25 より下げても DD は買えない。**
IS では **0.5 が底で 0.25・0.0 と戻る**（3.701 → 3.823 → 3.892%）。

**`Q004` に 0.25 を採ったのは一次近似の「月利÷DD が 0.25 で最大」からだったが、
実測の OOS では 0.5 でも DD はほぼ同じところまで落ちている。**
**「重み × 倍率」の面はまだ1点しか測っていない。** → 次ラウンドで掃く。

### 5.4 まだ答えが出ていないこと（ただし優先度は下がった）

**§5.1 の判定（IS 優先なら棄却）により、「重み × 倍率」の面を掃く価値は無くなった。**
IS 側に上り坂が無いことが重み4点（1.0 / 0.5 / 0.25 / 0.0）で確定したからである。

**ユーザーが「OOS を判定窓にする」と明示した場合にだけ**、次を測る:

- **`Q004` が証拠金の下で建つのか**（`MarginCapPct` 未測定）。倍率2 は `E004`/`E005` で
  cap 発動 499回だったので、**`Q004` も必ず発動する。**
- **`Q004` の equity DD**（本ラウンドは `CAP_LOG` を立て忘れたので取れていない・§4.5）。
  **倍率2 の equity DD は残高DD +15.8pt だったので、`Q004` は 50% 前後**と見込まれる。
- **重み 0.5 × 倍率2 / 重み 0.25 × 倍率3** など、面の残り。

**指示が無ければ次ラウンドは RSI 3枠の機構別退出**（Codex の棚卸しに残る最後の未測定軸）
にする。これは IS/OOS のトレードオフ問題と独立である。
