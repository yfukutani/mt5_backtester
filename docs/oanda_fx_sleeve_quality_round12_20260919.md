## 0. このラウンドが閉じるもの

Codex の棚卸し（[inventory](codex_oafx_inventory_20260919.md)）が「未実装・未測定」として
残した軸は3つ。**本ラウンドでそのうち SCA の2つを実装して測る。**
残る1つ（RSI 3枠の機構別退出）は改修が大きいので次ラウンドに回す。

[Codex の第12ラウンド査読](codex_oafx_round12_20260919.md)も
**「測る価値が残るのはその3軸だけ。PB 2枠・Pair・Carry には追加案は無い」**で一致した。

そこに、**deal ログの読み直し**（[SCA の退出の解剖](oanda_fx_sca_exit_anatomy_20260919.md)）で
新しく見つけた軸を1つ足す。

## 1. EA への追加（既定 0 で完全に inert）

| input | 内容 |
|---|---|
| `ScaRR_UJ` / `ScaRR_GJ` | >0 で SCA 親枠の TP を `rr×SL距離` に上書き。0 なら枠の既定 2.0 |
| `ScaOvsATR_UJ` / `ScaOvsATR_GJ` | >0 で「ブレイク終値のレンジ端からの超過幅 ÷ ATR」の上限。0 で無効 |

実装は `ScaRROver()` と `ScaOvsOK()` の2関数だけで、**`ProcSCA` の TP 計算と
ブレイク判定に1箇所ずつ足した**。`S[i].rr` を返すだけなので **GOLD や第2セッションの
SCA 枠には一切触れない**（magic で分岐）。

⚠️ **overshoot の超過幅は buffer を含む。** USDJPY は `buffer=0.10×ATR` なので、
上限を 0.10 以下にすると1本も通らない。**`OnInit` で 0.10 以下を弾く**ようにした。
GBPJPY は `buffer=0` なので下限の制約が無い。

## 3. 事前の予想（外れたら記録する）

| 案 | 予想 | 根拠 |
|---|---|---|
| Q005 / Q007（rr を**上げる**） | **ほぼ 0** | 実現 R倍率の最大は TP の 2.000R ちょうど。**2R を超えて走った取引は4ケースで1件も無い。** TP 発火は 1.0〜7.1% しかないので、93〜99% は no-op |
| Q006 / Q008（rr を**下げる**） | **両窓マイナス** | 実現 R を k で頭打ちにした下界が4ケースすべてマイナス（OOS GJ 426,099 → −304,632 @1R）。第17報の建値ストップと同じ機構 |
| Q009〜Q012（overshoot 上限） | **ほぼ 0** | overshoot が大きい取引は `dist=|entry−SL|` が大きく、risk% では**ロットが小さい**。この上限は**重みの軽い取引**を落とす。`ScaFilRangeMin`（重い取引を落とす）とは**逆向き**で、ブックへの効きは一桁小さいはず |
| Q001〜Q003（重みを下げる） | **OOS 悪化・IS 改善・DD は両窓で低下。単体では棄却**と予想 | SCA GBPJPY は円建てで OOS +426,099（ブックの30%）・IS −719,706。判定窓は OOS |
| **Q004（重み 0.25 ＋ 倍率2）** | **五分五分** | DD を揃えたときに月利が上がるかどうか。**ここが本命** |

**Q004 の理屈:** SCA GBPJPY は **全 deal の 48% を出しながら、1取引の期待値が ±0.02R しかない**
（OOS 平均 −0.016R / IS +0.018R）。**優位性の無い取引が口座リスクの大きな割合を食っている**なら、
**その分を優位性のある枠（PB GBPJPY は1取引 +1.1〜+1.7R）に回したほうが
同じ DD でより多く取れる**はずである。ただし——

> [!important] **第22報の「複利では枠別損益はブックの分解ではない」があるので、
> 「−426,099 になるはず」とは予測しない。** SCA GBPJPY を risk% から外した
> `ml/fxqual10` の `G008`/`G009` では、**枠自身は改善したのにブックは 250,202 悪化**した。
> 全枠が同じ equity を共有するので、**ある枠の利益が他の8枠のロットを大きくしている。**
> 重みを 0.25 にしたときにどちらが勝つかは、**測らないと分からない。**

## 4. 見込みについて、正直に

**このラウンドで月利6%に届く見込みは無い。**
Codex は3軸すべてを **「0.00pt 中心・定量幅なし」** と査読しており、
こちらの deal ログ解析も **TP 軸と overshoot 軸は事前期待ゼロ**を支持している。
**唯一、上振れの余地があるのは Q004（重み配分の付け替え）だけ**で、それも五分五分である。

**現在地は 全複利・倍率1 で OOS 2.488%。目標まで 2.4倍。**
