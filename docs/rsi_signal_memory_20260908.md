# RSIシグナル記憶の寿命と消費 — 棄却（2026-09-08）

**結論:** RSI逆張り枠のフラグ（RSI極値・BB逸脱の記憶）に寿命を設けたり、
MA反転で失効させたり、保有中に消費したりすると、**成績は悪化する**。
43案86run で、両窓改善かつ変更規模が足りるのは1案だけ、その規模も
**月利 +0.014%(IS) / +0.0013%(OOS)** と無視できる。**棄却。**

**仮説は逆だった。** フラグが長く残ること自体が、この戦略の収益源の一部だった。

---

## 1. なぜ測ったか

Codexによる未着手項目の調査（2026-09-07）で、FX側で残った未着手案7件のうち
4件がRSIのシグナル記憶まわりだった（提案16・17として `codex_50proposals` に記録され、
`codex_verification` で「今回スコープ外」のまま）。

RSI枠の周期・閾値・BB期間・偏差・レンジ判定・固定SL/TP・DPの各軸は
`param_reopt` / `codex500` で測定済みだが、**フラグの寿命と消費の仕様は未測定**だった。

## 2. 現行実装の事実

```
if(rbuy) S[i].wasOS=false; if(bbuy) S[i].belowBB=false;   // 注文分岐の中
```

フラグは**注文を出す分岐の中でしか消えない**。したがって

- 時間が経っても失効しない（何十本も前の逸脱で今のバーに入る）
- MAの反対側に移っても残る（レンジで立った記憶をトレンド移行後に使う）
- 同方向で保有中に完成したシグナルが消費されない（決済後に古い記憶で再入場）

## 3. 実装と回帰

`MIX_EA_SIMVERIFY.mq5` の `ProcRSI` にラボを追加（すべて既定OFF）。

| 入力 | 意味 |
|---|---|
| `RsiRSIFlagMaxBars` | RSI極値の記憶の寿命（バー数・0で無効） |
| `RsiBBFlagMaxBars` | BB逸脱の記憶の寿命（同上） |
| `RsiResetOnMAFlip` | MAの反対側に移ったら記憶を消す |
| `RsiConsumeWhileHeld` | 保有中に完成したシグナルも消費する |
| `RsiMemSleeveMask` | 適用枠 bit0=USDJPY / bit1=EURUSD / bit2=GBPUSD |

**回帰確認（重要）:** このラボは `ProcRSI` の中核（フラグの set/clear）に手を入れる。
既定値で1取引でもずれれば以降のFX側の測定が過去の基準と比較できなくなるため、
ラボ追加**前**のEA（SHA `63d549c8a5e9f37a`）で測った x1 の値と突き合わせた。

| 窓 | 純益 | 取引数 | 判定 |
|---|---:|---:|---|
| IS | 257,817（期待 257,817） | 1,595（期待 1,595） | **一致** |
| OOS | 119,537（期待 119,537） | 1,375（期待 1,375） | **一致** |

## 4. 測定と判定

43案・IS/OOS の **86run 全成功**。FX 9枠・`RefCap=78000`・`GlobalLotMult=1` 固定
（倍率の話とは分けて評価）。

**第一の判定は「RSI 3枠の合計純益が両窓とも改善するか」。**
最大DDは合否に使わない（`crypto_sleeve_sweep_20260907.md` の失敗を踏まえ、
単一イベントに支配されるため）。

**変更規模の代理指標**として枠別取引数差の絶対値合計を出し、
片窓でも10件未満なら判定不能とした。寿命を長く設定すれば何も変わらないので、
これがないと「効果なし」と「変化なし」を混同する。
（ただし同数の取引の入れ替わりは検出できないので、差0は効果なしの証明ではない。）

## 5. 結果 — 8ファミリー中7つで悪化

| ファミリー | 案数 | IS差の中央値 | OOS差の中央値 | 両窓正 | 変更規模充足 |
|---|---:|---:|---:|---:|---:|
| R1 RSI極値の寿命（2〜32本） | 5 | −1,386 | +612 | 1 | **0** |
| R2 BB逸脱の寿命（2〜32本） | 5 | **−9,366** | −4,196 | 0 | 0 |
| R3 両方の寿命 | 4 | −5,235 | −12,655 | 0 | 0 |
| R4 MA反転で失効 | 1 | **−10,903** | **−14,599** | 0 | 0 |
| R5 保有中の消費 | 1 | −1,876 | −2,229 | 0 | 0 |
| R6 組み合わせ | 6 | **−13,687** | **−16,018** | 0 | 0 |
| R7 枠別マスク | 12 | ±0 | ±0 | 2 | **1** |
| R8 寿命の細分 | 8 | −3,524 | −120 | 1 | 0 |

R7 の中央値が ±0 なのは、マスクで対象外にした枠が多く「何も起きていない」案が
半数を占めたため。

### 唯一の候補も規模が無視できる

**M025（USDJPYのみ・BB寿命8本）**: IS +4,235 / OOS +359。
入金50万換算で **+0.014%/月(IS) / +0.0013%/月(OOS)**。
月利6%目標に対して 0.2% / 0.02%。43案試したうちの1件としてはノイズと区別できない。

## 6. なぜ逆だったか

「古い記憶を使うのは害」という仮説だったが、**記憶を消すほど悪化した**。
特に組み合わせ（R6）とMA反転失効（R4）で大きく崩れる。

**フラグが長く残ること自体が、この戦略の収益源の一部**だったと読むのが妥当である。
逸脱から時間が経っても、閾値を戻る動きに平均回帰の情報が残っている。
設計として意図的でなかったとしても、結果的に機能していた。

**教訓:** 「実装上の不備に見えるもの」が収益源であることがある。
コード監査で見つけた不整合を、測定なしに直してはいけない。

## 7. 判断

**棄却。** 本番EAへの実装は行わない。検証EAのラボは既定OFFのまま残す
（`RsiBBFlagMaxBars=0` / `RsiRSIFlagMaxBars=0` / `RsiResetOnMAFlip=false` /
`RsiConsumeWhileHeld=false`）ので本番の挙動には影響しない。
