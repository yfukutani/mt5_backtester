## 3. RV01 は「今日いちばん大きい改善」だが採らない

**OOS +15,585 は、本日の全ラウンドで最大の単一枠の改善である**
（PB slope の +7,429 の2倍）。月利にすると **0.428% → 0.485%（+0.057pt）**、
**最大DD も 5.27% → 4.14% と大きく下がる。**

**それでも採らない。IS が −4,281 で符号が割れるからである。**
そしてこれは**測る前に予測されていた**（`measure.py` に「予測 OOS +15,585 / IS −4,281」と明記）。

> [!warning] **もし OOS だけを見ていたら、これは今日いちばん魅力的な案に見える。**
> 第16報の V007（Codex 第1推奨・OOS +4,558 / IS −15,244）と**同じ構造**である。
> **OOS で最大の改善が、IS で符号を失う。** この材料では繰り返し起きる。

## 4. 「結論だけ出てバックテストが無い案」の2件目も棄却

`ScaFilRangeMin`（レンジ幅の下限・`oanda_fx_last_axes_20260915.md` の **B1**）も、
**MT5 で走ったことが一度も無かった**（`ml/fxqual5` で見つけた `ScaFilHourFrom` と同じ穴）。

**RV07（GJ のみ）は OOS −54,524 で、このラウンド最大の悪化。**
`oanda_fx_last_axes` は B1 について GBPJPY で **OOS −84.4% / −80.0%**（上位25%/50%閾値）と
記録しており、**方向は一致している**（閾値が違うので金額は比較できない）。

### ⚠️ ただし RV06 を枠別に割ると、SCA USDJPY だけは両窓プラスだった

| 枠 | OOS Δ | IS Δ |
|---|---:|---:|
| SCA GBPJPY | **−54,524** | **−5,374** |
| **SCA USDJPY** | **+3,991** | **+3,393** |
| ブック全体（RV06） | −50,526 | −2,109 |

**ブック全体では大きな棄却だが、SCA USDJPY 単独では両窓プラスである。**
そして **SCA USDJPY だけに掛ける構成は、このラウンドに含まれていない**
（RV06 は2枠・RV07 は GBPJPY のみ）。

`oanda_fx_last_axes` は USDJPY の B1（上位50%閾値）を **OOS +4,975** と見積もっていた。
**桁は合う**（閾値が違うので一致はしない）。同 doc は同時に
**「金額が小さすぎて採否を論じる意味がない」**とも書いており、**その評価は正しい**
（+3,991円は OOS 55か月で幾何月利 **+0.015pt** 相当）。

**枠別の効果は加算的（4例で確認済み）なので、UJ 単独ならブック Δ は
+3,991 / +3,393 になるはずである。** 確認のため `ml/fxqualcfm` に
**F006（UJ 単独）** と **F007（採用候補3件の合成）** を足した。

> [!warning] **これは「結果を見てから枠を選んだ」形である。**
> ただし第7ラウンドの Z007（SCA USDJPY だけ建値ストップ）と違い、
> **選ぶ前に予測が存在した**——`oanda_fx_last_axes_20260915.md` は 2026-09-15 の時点で
> 「B1 は SCA USDJPY の OOS 赤字を黒字に変える（+4,975円）」と書いている。
> **後付けではないが、効き幅は月利 +0.015pt である。**

## 5. このラウンドで確定した棄却

| 軸 | 判定 |
|---|---|
| SCA のリバーサル条件を**入口ゲート**にする | **棄却**（OOS +15,585 だが IS −4,281 で割れる） |
| 同・**逆**（リバーサル足を落とす） | **棄却**（両窓大幅マイナス。この枠の利益源そのもの） |
| SCA USDJPY のリバーサル部分集合 | **棄却**（両方向とも割れるか両窓マイナス） |
| **`ScaFilRangeMin`（レンジ幅下限）** | **棄却**（GJ で OOS −54,524） |

**これで SCA 2枠の入口側の軸は、時間帯・方向・レンジ幅・リバーサル条件のすべてが閉じた。**
退出側も第7ラウンド（建値ストップ）で閉じている。**SCA はこのテーマでは打ち止めである。**
