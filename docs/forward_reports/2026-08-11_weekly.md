しかし **肝心の実行主体が変わっていない**:

| 項目 | 現在の値 | 判定 |

| タスクの `<Description>` | `EA MT5 watchdog. S4U + AtStartup so it survives an unattended reboot (S-5).` | 意図は S4U |
| 実際の `<LogonType>` | **`InteractiveToken`** | ❌ **S4U になっていない** |

  **BootTrigger が発火しても実行されない**。起動時トリガーを足しただけでは 07-31 の穴は塞がっていない。

  `AutoAdminLogon=0` のため成立していない。**つまり2つある経路のどちらも完成していない。**
- **前回 improvements が「説明（ログオン非依存）と実装（InteractiveToken）が矛盾している」と指摘したのと、まったく同じ種類の欠陥が
  是正後のタスクにも残っている。**
- **未検証**: 08-02 23:21 の再起動（ユーザーによる修正作業時）を最後に**再起動が発生していない**（uptime 8.87日）ため、
