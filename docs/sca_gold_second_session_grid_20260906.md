# SCA GOLD 第2セッション — 1時間刻みの精査（2026-09-06）

**結論:** 前ラウンドの推奨 S2046（13-15時）は**単独スパイクではなかった。**
締切・強制決済・RR の各軸では台地になっており、その中心に位置する。
ただし**窓（開始時刻）軸だけは台地ではなく、13時開始だけが特異的に通る。**
採用可能という判断は維持するが、これは「GOLD の 13時台のレンジが効く」という
時間帯固有の効果であり、その性質が将来も続くかどうかが唯一にして最大のリスクである。

---

## 1. なぜ測ったか

前ラウンド（`sca_gold_second_session_20260905.md`）はレンジ窓を**2時間刻みでしか
振っていない**。推奨した S2046(13-15時) が

- 周辺も効いている**台地**なのか
- たまたま当たった**単独スパイク**（＝過学習）なのか

が未確定のまま残っていた。台地なら採用の確度が上がり、スパイクなら落とす。

## 2. 測定

`Sca2*` 入力はすでに実装済みなので**EAは変更していない**。56案×2窓＝112run、全成功。
XM端末・入金50万・JPY建て・every_tick。所要2時間31分。

W1で開始時刻 9..16時 × レンジ幅 1..3時間 の**23窓すべて**を掃いた。
前ラウンドの推奨 S2046 そのものを **S2B014 として同一掃引に含めてある**ので、
基準点との比較がスワップ率ドリフトを跨がない。

### 掃引中のEA差し替え検知

本掃引の裏で別ラウンド（PB2）用のEA変更をコンパイルしている。掃引中にEAが
入れ替わると以降のrunだけ別バイナリで測ったことになり、しかもMT5は未知のSET
パラメータを黙って無視するので失敗が表に出ない（`scaexit1` で実際に偽の測定を出した）。
測定ドライバに配備済み `.ex5` のSHA-256を1runごとに突き合わせるガードを入れ、
112run を通じて `bd9e38e0486c07a3` が不変であることを確認した。

## 5. 何が台地で、何が台地でないか

### 台地である軸

- **エントリー締切:** 16h / 17h / 18h / 19h / **20h** / 21h / 22h の**7水準すべてが通過**。
  S2046 の 20h はその中心にある。
- **強制決済:** 21h / 22h / 23h が通過。
- **レンジ幅フィルタ:** 0.5〜0.8 と 0.5〜1.0 がDD優位で上位（0.40〜1.00 が中心）。

パラメータを動かしても効果が続くので、特定値に当たったわけではない。

### 台地でない軸 — ここが本質的なリスク

**窓（開始時刻）軸では、23窓のうち両ゲートを通ったのは 13-14時 と 13-15時 の2つだけ。**
そして**通過した13案は全て13時開始**である。

12-14時（S2B011/S2B051/S2B052）は頑健性ゲートを通る（S2B052 は IS除外後 +39,751 /
OOS除外後 +6,293 と S2046 を上回る）が、**DD優位ゲートで落ちる**。
9-11時（S2B002）は IS除外後 +46,091 で全案中最大だが、OOS年次が 3/6 と一貫性を欠く。

つまりこれは「米国時間帯なら広く効く」のではなく、**13時台のレンジが特異的に効く**現象である。

### RR軸の非単調性 — 指標のノイズに注意

RR は 1.3 / 1.5 / 1.7(中心) / 2.4 が通過し、**1.9 と 2.1 が落ちる**（IS優位 −0.01 / −0.00）。
物理的に説明のつかない並びで、**DD優位の指標は 0 近傍でノイズに埋もれる**ことを示す。
この指標の細かい順位を読んではいけない。0を跨ぐかどうかだけを見る。

## 6. 推奨 — S2046 を維持する

**前ラウンドの推奨 S2046（S2B014）をそのまま維持する。**

S2B026（締切18h）と S2B027（締切19h）は数字上わずかに上回るが、差はスワップ率
ドリフト（3日で6.2%の実測がある）の範囲内で、選び直す根拠にならない。
S2046 は締切軸の台地の中心にあり、両窓とも年次 5/6 黒字という一貫性を満たす、
選択として最も無難な位置にある。

```
Sca2Enable     = true
Sca2RangeStart = 13
Sca2RangeEnd   = 15
Sca2TradeEnd   = 20
Sca2ForceClose = 23
Sca2MinRange   = 0.40
Sca2MaxRange   = 1.00
Sca2Buffer     = 0.0
Sca2RR         = 1.7
Sca2SkipFriday = true
Sca2RevBoost   = true
Sca2BoostMult  = 2.0
Sca2Lot        = 0.01
```

### 規模は変わらない

入金50万・非複利で 最良年除外後 **+0.14%/月(IS) / +0.02%/月(OOS)**。
月利6%目標に対して 2.3%。**採用しても運用目標を動かす規模ではない。**
本ラウンドで増えたのは金額ではなく、この施策が本物であるという確度である。

## 7. 本番投入の前に必要なこと（前ラウンドから変わらず）

1. **OANDA端末での再測定。** 本測定はXM(GOLD)。本番はOANDA(XAUUSD)でフィードが違う。
   OANDA 5端末は MT5 の LiveUpdate に捕まって使用不能のため、その解消後。
2. **本番EA（`MIX_EA.mq5` / `MIX_EA_OANDA.mq5`）への実装。** 現在は検証EAにのみある。
3. 13時開始という選択が時間帯固有である以上、**フォワードでの継続確認**が要る。
