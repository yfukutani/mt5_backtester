# SCA GOLD 第2セッション — 小さいが実在する追加収益源（2026-09-05）

**結論:** SCA GOLD に米国時間帯の第2セッションを追加すると、**両窓で利益が2〜3割増え、
DDはほぼ増えない（OOSではむしろ減る）。** 他枠への副作用もない。
ただし**利益はGOLDが激しくトレンドした年に強く偏り**、最良年を除くと寄与は
既存枠の3〜4割にとどまる。**採用は可能だが、運用目標（月利6%）を動かす規模ではない。**

---

## 1. なぜここを見たか

GOLDの収益アップで、これまで測った領域はすべて閉じている。

| 領域 | 案数 | 結果 |
|---|---:|---|
| GOLD別戦略7案 | 7 | 全滅（`rejected_strategies.md` §1） |
| 利益保護（BE/トレール/giveback/部分利確） | 500 | 採用ゼロ |
| SCA GOLD 利確側（RR/TP/強制決済/締切） | 290 | 採用ゼロ |
| GOLD DD低減（エントリー品質・重複制御） | 1,380 | 保有上限64バーのみ |
| PB/SCA GOLD の risk% サイジング | 42 | 固定ロットに全面的に劣る |
| **SCA GOLD 第2セッション** | 70 | **本書** |

既測定のファミリーを洗い出すと、**PB GOLD のエントリー系は11系統測られているのに
SCA GOLD は4系統しかなく**、しかも**第2セッションは文書に言及すら無かった**。

SCA GOLD は IS 242取引で GOLD の取引数の8割を占める主力枠だが、
**1日1レンジ（1-9時）しか使っておらず米国時間帯が丸ごと未利用**だった。
GOLD の弱点は「630取引/10年＝月5.5回」という薄さなので、取引数を増やすこと自体に価値がある。

## 2. 実装

`MIX_EA_SIMVERIFY.mq5` に**別magic（20261003）の第2枠**を追加（既定OFF）。
既存の SCA 機構（`ProcSCA`）をそのまま使うので、レンジ時刻・締切・強制決済・
レンジ幅フィルタ・RR・バッファ・Boost をすべて独立に指定できる。
第1セッション（20261002）には一切触れていない。

**回帰:** `Sca2Enable=false` で純益 379,590・取引305（追加前 379,580・305取引）と実質一致。

## 3. 実測（XM・入金50万・70案140run 全成功）

### 3.1 確定測定（基準と候補を同一セッションで連続測定）

| ブック | 窓 | 基準 純益 | 案 | 純益 | 差 | 倍率 | DD差 |
|---|---|---:|---|---:|---:|---:|---:|
| GOLD 3枠 | IS | 379,590 | S2047 | 514,474 | **+134,884** | 1.355 | +0.304pt |
| GOLD 3枠 | IS | 379,590 | S2057 | 509,779 | +130,189 | 1.343 | **−0.008pt** |
| GOLD 3枠 | IS | 379,590 | S2046 | 502,827 | +123,237 | 1.325 | +0.296pt |
| GOLD 3枠 | OOS | 76,603 | S2047 | 101,478 | **+24,875** | 1.325 | **−0.027pt** |
| GOLD 3枠 | OOS | 76,603 | S2046 | 97,336 | +20,733 | 1.271 | **−0.027pt** |
| **フルブック** | IS | 487,081 | FULL_S2046 | 610,318 | **+123,237** | 1.253 | +0.219pt |
| **フルブック** | OOS | 98,202 | FULL_S2046 | 118,935 | **+20,733** | 1.211 | **−0.099pt** |

**第2セッションの寄与は暗号3枠の有無で完全に同一**（IS +123,237 が両ブックで一致）。
**PB GOLD は全案・全窓で完全に不変。** 純粋に加算的で、他枠への副作用がない。

### 3.2 「枠を足すと第1が−3,530円動く」— 第2セッション固有ではない

| 構成 | SCA第1 の純益（IS） |
|---|---:|
| GOLD 2枠のみ（基準） | 182,650 |
| ＋第2セッション | 179,120 |
| ＋暗号3枠（第2セッションなし） | **179,120** |

**枠を1つでも追加すると同じ −3,530円 が起きる。** 第2セッションが第1を食っているのではなく、
建玉が増えたときのテスターの約定処理の差である。したがって
「第2セッションの正味寄与」からこれを差し引く必要はない。

### 3.3 固定ロットで倍率を上げた場合との比較

固定ロットの「効率」は倍率によって変わる（DDが劣線形に増えるため x3=1.38 / x5=1.75 /
x8=2.32）ので、利益1.2〜1.4倍の施策と直接比べてはいけない。
**同じ純益倍率を固定ロットで出したときのDD倍率**（実測から `DD倍率 ≈ 倍率^0.71` で内挿）と
突き合わせる。

**70案中27案が、両窓とも「固定ロットで同じ利益を出すよりDDが小さい」。**
S2057 は IS 利益+34%でDD増加ゼロ、OOS 利益+25%でDD低下。
倍率を上げる方法では原理的に不可能な形で、**時間帯の異なる取引を足したことによる分散効果**である。

## 4. ⚠️ 頑健性 — 利益はGOLDが走った年に偏る

GOLDは 2026年（IS）と 2020年（OOS）に激しくトレンドしており、**GOLD枠の利益はどれも
その年に偏る**。偏り自体は失格理由にならないが、その年を除いても黒字かを見る。

| | IS 計 | IS 最良年除外後 | OOS 計 | OOS 除外後 | 年次黒字 |
|---|---:|---:|---:|---:|---|
| **S2046**（バッファ0.0） | +123,237 | **+35,991** | +20,733 | **+4,876** | IS 5/6・OOS 5/6 |
| S2047（バッファ0.02） | +134,884 | +36,412 | +24,875 | +3,571 | 5/6・4/6 |
| S2057（Boostなし＋金曜） | +130,189 | +39,106 | +19,330 | **−3,740** | 5/6・3/6 |
| 既存 SCA第1 | — | +81,175 | — | +16,257 | — |
| 既存 PB GOLD | — | +115,448 | — | +12,988 | — |

**24/70 が「最良年を除いても両窓黒字」を通過。** ただし
**第2セッションの寄与は既存枠の3〜4割**にとどまる。

集中度も既存枠より高い（上位3件の寄与が 80〜116% 対 37〜65%）。

### 良い兆候

- **バッファ全水準（0.0〜0.3）が上位**に入っており、特定値に当たったスパイクではない
- レンジ窓も 11-13h / 12-15h / 13-15h / 13-16h と複数が通過しており、面で効いている
- **年次 5/6 黒字が両窓で成立**（既存枠と同水準の一貫性）

## 5. 推奨

**S2046 を推奨する。** 最良年を除いた黒字幅が両窓で最も大きく、年次一貫性も両窓 5/6。

```
Sca2Enable     = true
Sca2RangeStart = 13     // 第2レンジ 13-15時（サーバー時刻）
Sca2RangeEnd   = 15
Sca2TradeEnd   = 20     // エントリー締切
Sca2ForceClose = 23     // 強制決済
Sca2MinRange   = 0.40
Sca2MaxRange   = 1.00
Sca2Buffer     = 0.0    // ブレイク判定バッファなし
Sca2RR         = 1.7
Sca2SkipFriday = true
Sca2RevBoost   = true
Sca2BoostMult  = 2.0
Sca2Lot        = 0.01
```

より高いリターンを取るなら S2047（バッファ0.02）が IS +134,884 / OOS +24,875 と上回るが、
最良年を除いたOOSは +3,571 と S2046 の +4,876 に劣る。

### 規模の評価（入金50万・非複利）

| | 月利換算 | 月利6%目標に対して |
|---|---:|---:|
| 見かけ（IS） | +0.41% | 6.8% |
| 見かけ（OOS） | +0.075% | 1.3% |
| **最良年除外後（IS）** | **+0.14%** | **2.3%** |
| **最良年除外後（OOS）** | **+0.02%** | 0.3% |

**採用しても運用目標を動かす規模ではない。** ただしこれまでの2,282案が
すべて採用ゼロだった中で、**両窓で一貫して正・DD中立・他枠に副作用なし**という
条件を満たした最初の施策である。

## 6. 本番投入の前に必要なこと

1. **OANDA端末での再測定。** 本測定はXM端末（GOLD）で行った。本番はOANDA（XAUUSD）で、
   フィードとスプレッドが違う。OANDA 5端末は現在 MT5 の LiveUpdate に捕まって
   使用不能なので、その解消後に測り直す必要がある。
2. **本番EA（`MIX_EA.mq5` / `MIX_EA_OANDA.mq5`）への実装。** 現在は検証EAにのみある。
3. 第2セッションの建玉が第1と同時に持たれる局面のリスク確認（本測定では
   DDが増えていないが、フォワードでの実地確認が要る）。

## 7. 測定上の注意（次ラウンドへの申し送り）

- **XM版EAの deal ログの `profit_jpy` はJPY建て口座では使えない。**
  `profit_jpy = profit × USDJPY` を無条件に計算しており、USD建て口座専用
  （gold_dd2 は入金900 USD）。JPY建てでは **`profit` 列が正しい値**。
  本ラウンドでは最初これを踏み、枠別純益が110倍に膨らんだ。
  再集計後に「枠別合計＝テスター純益」が全140行で一致することを確認した。
- **固定ロットの効率は倍率で変わる。** 施策と比べるときは必ず**同じ利益水準**で
  DDを突き合わせること。効率の絶対値どうしを比べると誤った結論になる。
- **枠を追加すると既存枠の損益が僅かに動く**（本ラウンドで −3,530円）。
  第2セッション固有ではなく暗号枠を足しても同じ量が動くので、
  施策の寄与から差し引くべきではない。
